# 💬 사내 규정 AI 챗봇 (RAG) — 사용설명서

> 이 폴더의 `README.md`는 16번 **실습 안내서**예요. 만든 챗봇을 **쓰는 법**은 이 파일에 있어요.

회사 규정 문서(`docs/`)를 넣어 두면, 직원이 묻는 말에 **문서에 적힌 내용만 근거로** Claude가 답해 주는 챗봇이에요.
문서에 없는 질문에는 지어내지 않고 **"문서에 없는 내용이에요. 담당 부서에 확인해 주세요."**라고 답하고, 답마다 **근거 문서 이름**을 보여 줘요.

---

## 1. 무엇을 하나요?

RAG = **찾아서(검색) → 근거를 건네고 → 답하게** 하기. 비유하면 **"규정집 포스트잇을 뒤져서 해당 장만 알바생에게 건네주는 것"**이에요.

```
docs/ 규정 문서 5개
    │  ① 1_청크나누기.py  — 문서를 한 줄씩 '포스트잇'(조각)으로 자르기
    ▼
조각목록.json (조각 22개)
    │  ② 검색 — 질문과 '두 글자 묶음'이 많이 겹치는 조각 3개 고르기 (AI 안 씀)
    ▼
고른 조각 3개 + 질문
    │  ③ Claude — 조각에 적힌 내용만으로 1~3문장 답 + 실제로 쓴 조각 번호
    ▼
🤖 답  +  📄 근거: 01_휴가규정.md
```

| 파일 | 하는 일 | AI 사용 |
|---|---|---|
| `1_청크나누기.py` | `docs/*.md` → `조각목록.json` | ❌ |
| `2_검색하기.py` | 테스트 질문 9개로 검색만 시험 (1등 조각이 정답 문서인지) | ❌ |
| `3_답하기.py` | 질문에 답하기 (질문을 직접 넣을 수도 있음) | ✅ |
| `4_채점하기.py` | 테스트 질문 9개를 묻고 Claude 채점자가 채점 → `결과/채점결과.csv` | ✅ |
| `5_근거표시.py` | 답 아래에 근거 문서 이름 붙이기 | ✅ |
| `6_웹채팅.py` + `채팅화면.html` | 브라우저 채팅 화면 (`http://localhost:8000`) | ✅ |
| `공통.py` | 위 파일들이 같이 쓰는 부품 (검색, Claude 부르기, 규칙) | — |

## 2. 설치

### ① 파이썬 가상환경 — 03번 것을 빌려 써요

이 챗봇은 따로 가상환경을 만들지 않고 **`03_메일분류/.venv`**(파이썬 3.12, `anthropic`·`python-dotenv`)를 빌려 써요.
그래서 모든 명령이 `python3`가 아니라 **`../03_메일분류/.venv/bin/python`**으로 시작해요.

03번 가상환경이 없는 새 컴퓨터라면 (실습키트 폴더에서):

```bash
cd 03_메일분류 && uv venv --python 3.12 && uv pip install anthropic python-dotenv
```

### ② Claude API 키 — 03번 금고를 빌려 써요

키는 **`03_메일분류/.env`** 한 곳에만 있어요 (`.gitignore`로 GitHub 제외). 이 폴더로 **복사하지 않아요.**

```
ANTHROPIC_API_KEY=sk-ant-...
```

키는 [Claude Console](https://console.anthropic.com)에서 만들어요. 쓴 만큼 요금이 나가요.

## 3. 사용법

**터미널에서 이 폴더로 먼저 들어가요.**

```bash
cd 16_문서기반AI챗봇
```

### 처음 한 번 (문서를 바꿨을 때도)

```bash
../03_메일분류/.venv/bin/python 1_청크나누기.py
```

### 질문 하나 해 보기

```bash
../03_메일분류/.venv/bin/python 3_답하기.py "반차 시간이 어떻게 돼요?"
```

질문 없이 실행하면 예시 질문 3개(연차·배우자 출산·주차비)에 답해요.

### 웹 채팅 화면으로 쓰기

```bash
../03_메일분류/.venv/bin/python 6_웹채팅.py > /dev/null 2>&1 &
```

```bash
open http://localhost:8000
```

다 쓰면 서버 끄기:

```bash
kill %1
```

> `&`는 서버를 **뒤에서** 돌려서 같은 터미널을 계속 쓸 수 있게 해요. `kill %1`은 뒤에서 돌던 1번 작업을 꺼요.

### 챗봇 점검하기 (문서나 규칙을 바꾼 뒤)

| 명령 | 확인할 숫자 |
|---|---|
| `../03_메일분류/.venv/bin/python 2_검색하기.py` | 검색: 문서가 있는 질문 **8개 중 8개** 1등 조각이 정답 문서 |
| `../03_메일분류/.venv/bin/python 4_채점하기.py` | 채점: **9문항 중 9개** 정답 |
| `../03_메일분류/.venv/bin/python 5_근거표시.py` | 근거 문서 표시가 정답표와 같은 개수 |

## 4. 결과 예시

`1_청크나누기.py`:

```
✂️  문서 5개를 조각 22개로 나눴어요.
  01_휴가규정.md: 5개
  02_출장비규정.md: 4개
  ...
```

`3_답하기.py "질문"` 의 답 줄 (2026-11-22, 2번씩 실행해 같은 답 확인):

```
❓ 배우자 출산하면 휴가 며칠?
   🤖 답: 배우자 출산 시 경조휴가는 10일이에요.

❓ 주차비 지원 되나요?
   🤖 답: 문서에 없는 내용이에요. 담당 부서에 확인해 주세요.
```

웹 채팅과 `5_근거표시.py`는 답 아래에 `📄 근거: 01_휴가규정.md` 처럼 **근거 문서 이름**을 붙여 줘요.

> AI 답은 **실행할 때마다 문장이 조금씩 달라질 수 있어요.** 숫자(10일)와 "문서에 없다"는 판단이 같으면 정상이에요.

## 5. 내 문서로 바꾸기 (예: 고객 CS 챗봇)

1. `docs/`에 `.md` 문서를 넣어요. **이 모양**이어야 조각으로 잘려요:
   ```
   # 문서 제목           ← 한 개
   ## 소제목             ← 여러 개 가능
   - 항목 한 줄           ← 이 줄 하나가 조각 하나
   ```
   `-`로 시작하지 않는 줄(그냥 문단)은 **조각이 안 돼요** = 챗봇이 못 찾아요.
2. `1_청크나누기.py`를 다시 실행해요.
3. 회사 이름·말투를 바꾸려면 `공통.py`의 `지시문`(“너는 (주)연습상사의 사내 규정 안내 챗봇이야…”)을 고쳐요.
4. `테스트질문_정답.csv`에 내 질문·기대답변·근거문서를 넣고 `4_채점하기.py`로 점검해요.

## 6. 주의사항

| 상황 | 이렇게 돼요 / 이렇게 하세요 |
|---|---|
| `python3 3_답하기.py`로 실행 | ❌ `No module named 'anthropic'` — 꼭 `../03_메일분류/.venv/bin/python`으로 실행 |
| 03번 `.env`가 없음 / 키가 틀림 | ❌ Claude 인증 오류. `03_메일분류/.env`의 `ANTHROPIC_API_KEY` 확인 |
| 문서를 고쳤는데 답이 그대로 | `1_청크나누기.py`를 다시 안 돌린 것. 챗봇은 `docs/`가 아니라 `조각목록.json`을 읽어요 |
| `.py` 코드를 고쳤는데 웹 채팅이 그대로 | 서버는 켤 때 코드를 한 번만 읽어요 → `kill %1` 후 다시 켜기 (조각목록만 바뀐 건 다시 켤 필요 없음) |
| `Address already in use` | 8000번 서버가 이미 켜져 있어요 → `kill %1` 또는 열려 있는 다른 터미널 탭에서 끄기 |
| 검색은 '글자 겹침' 방식 | 같은 뜻 다른 말(“휴가” vs “연차”)은 못 찾을 수 있어요. 문서에 자주 쓰는 말을 넣어 두면 좋아요 |
| 요금 | 질문 하나마다 Claude를 1번 (채점은 2번) 불러요. `4_채점하기.py`는 9문항 × 2번 |
| 답 앞에 `<final>` 같은 글자 | 가끔 섞여 나와서 `공통.py`가 자동으로 지워요 |
| 개인정보 | `docs/`에 고객 실명·연락처를 넣지 마세요. 조각이 Claude API로 전송돼요 |
