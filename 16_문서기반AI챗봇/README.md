# 16. 문서 기반 AI 챗봇 (RAG)

> **얻는 능력:** 회사 문서를 근거로 답하는 AI를 만드는 능력 — 기업 AI 도입의 핵심

**왜 배우나요?** '우리 회사 규정 물어보면 답해 주는 챗봇'은 지금 기업들이 가장 많이 만들고 싶어 하는 AI예요. 핵심은 '문서에 없으면 모른다고 답하게' 만드는 것입니다.

## 📁 들어 있는 파일
- `docs/01~05_*.md` – 가상 회사 '(주)연습상사'의 사내 규정 5개 (휴가·출장비·보안·복지·재택)
- `테스트질문_정답.csv` – 챗봇 성능을 채점할 질문 9개와 기대 답변

## 🧭 기본 미션 (순서대로)
1. RAG가 뭔지 Claude Code에 설명을 듣는다 (검색 → 근거 찾기 → 답변)
2. docs 폴더의 문서를 잘게 나눠(청크) 검색할 수 있게 만든다
3. 질문하면 관련 문서 조각을 찾아 보여 주는 단계까지 먼저 만든다
4. 찾은 조각을 근거로 AI가 답하게 연결한다 (Claude API 필요)
5. 테스트 질문 9개로 채점한다. 특히 마지막 '주차비' 질문에 '문서에 없다'고 답하는지 확인

## 🔥 도전 미션 (기본을 끝냈다면)
- 답변마다 근거 문서 이름을 표시하기
- 간단한 웹 채팅 화면 붙이기
- 문서를 추가하면 자동으로 반영되게 만들기

## 💬 Claude Code에 이렇게 말해 보세요
막히면 아래 문장을 그대로 복사해서 써도 돼요. 단, **먼저 결과를 직접 실행해 보고, 코드에서 모르는 줄은 "이 줄이 뭐 하는 거야?"라고 꼭 물어보세요.** 그래야 실력이 남아요.

```
RAG가 뭔지 초보자에게 설명하듯 알려 주고, docs 폴더 문서로 사내 규정 챗봇을 만드는 계획을 세워 줘.
```
```
1단계로 질문을 넣으면 관련 문서 조각만 찾아서 보여 주는 검색기를 만들어 줘. AI 답변은 다음 단계에서 붙일게.
```
```
테스트질문_정답.csv 로 챗봇을 채점해 줘. 틀린 답은 왜 틀렸는지 분석해 줘.
```
