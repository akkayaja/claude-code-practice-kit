# 03. 메일과 첨부파일 자동 분류

> **얻는 능력:** 규칙을 정해 업무 흐름을 자동으로 나누는 능력

**왜 배우나요?** 메일을 열어 보고 폴더로 옮기고 첨부파일을 저장하는 일은 매일 반복돼요. 실제 메일함 대신 메일 파일(.eml)로 안전하게 연습합니다.

## 📁 들어 있는 파일
- `inbox/mail_01~20.eml` – 가짜 업무 메일 20통 (일부는 CSV 첨부파일 포함)
- `정답_분류표.csv` – 내 결과와 비교할 정답 (먼저 보지 마세요!)

## 🧭 기본 미션 (순서대로)
1. 메일 파일 하나를 텍스트 편집기로 열어 구조(제목·보낸사람·본문·첨부)를 확인한다
2. 모든 메일의 제목·보낸사람·날짜를 표로 뽑는다
3. 분류 규칙을 직접 정한다: 견적요청 / 청구서 / 고객문의 / 사내공지 / 스팸
4. 규칙대로 메일을 `분류결과/카테고리명/` 폴더로 복사한다
5. 첨부파일은 `첨부파일/` 폴더에 따로 저장한다
6. `정답_분류표.csv`와 비교해 정확도(%)를 계산한다

## 🔥 도전 미션 (기본을 끝냈다면)
- 키워드 규칙 대신 AI(Claude API)에 분류를 맡기고 정확도를 비교하기
- 청구서 메일에서 금액만 뽑아 합계 내기
- 고객문의 메일에 보낼 답장 초안 자동 작성

```

```
```

```
