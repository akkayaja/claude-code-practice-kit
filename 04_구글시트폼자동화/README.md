# 04. 구글폼·시트 자동화

> **얻는 능력:** 협업 도구(구글 시트·Apps Script)를 자동화하는 능력

**왜 배우나요?** 작은 회사일수록 구글폼으로 신청을 받고 시트로 관리해요. 신청이 들어오면 자동으로 정리·알림이 가게 만들 줄 알면 바로 써먹습니다.

## 📁 들어 있는 파일
- `data/특강신청_응답.csv` – 구글폼에서 내보낸 것과 같은 형태의 특강 신청 응답 60건

## 🧭 기본 미션 (순서대로)
1. 파이썬으로 먼저 연습: 과목별·일정별 신청 인원을 집계한다
2. 개인정보 동의가 '아니오'인 신청자를 걸러 낸다
3. 같은 사람이 중복 신청했는지 확인한다
4. 구글 시트를 하나 만들고 CSV를 업로드한다 (파일 → 가져오기)
5. Claude Code에 Apps Script 코드를 받아 시트의 '확장 프로그램 → Apps Script'에 붙여 넣는다
6. 스크립트로 '과목별 요약' 시트가 자동 생성되게 만든다

## 🔥 도전 미션 (기본을 끝냈다면)
- 새 응답이 들어오면 신청자에게 확인 메일 자동 발송 (내 메일로만 테스트)
- 정원(과목당 15명) 초과 시 '대기' 표시
- 문의사항이 있는 행만 노란색으로 칠하기

```
```

```
```
