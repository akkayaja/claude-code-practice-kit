# 02. 여러 파일을 모아 보고서 자동 생성

> **얻는 능력:** 흩어진 자료를 모아 정해진 양식의 보고서로 만드는 능력

**왜 배우나요?** '각 팀 실적 취합해서 주간보고 올려'는 직장인 업무 1순위예요. 이걸 버튼 하나로 끝내는 사람이 되는 연습입니다.

## 📁 들어 있는 파일
- `data/○○팀_11월_실적.xlsx` – 5개 팀의 주차별 업무 실적
- `template/주간보고_양식.md` – {{ }} 자리에 값을 채워 넣는 보고서 양식

## 🧭 기본 미션 (순서대로)
1. 팀별 엑셀 하나를 열어 구조를 확인한다
2. 5개 팀 파일을 읽어서 전체 건수·완료 건수·달성률을 계산한다
3. 팀별 실적을 표로 만든다
4. '이슈사항'이 비어 있지 않은 행만 모아 이슈 목록을 만든다
5. 양식의 {{ }} 자리를 채워 `결과/주간보고_11월.md`로 저장한다

## 🔥 도전 미션 (기본을 끝냈다면)
- 주차를 입력받아 해당 주차만 보고서로 만들기 (예: `python report.py 3주차`)
- 결과를 Word(.docx)나 PDF로도 저장하기
- '지연' 상태가 많은 팀을 자동으로 강조하기

## 💬 Claude Code에 이렇게 말해 보세요
막히면 아래 문장을 그대로 복사해서 써도 돼요. 단, **먼저 결과를 직접 실행해 보고, 코드에서 모르는 줄은 "이 줄이 뭐 하는 거야?"라고 꼭 물어보세요.** 그래야 실력이 남아요.

```
data 폴더의 팀별 실적 엑셀을 모두 읽어서 template/주간보고_양식.md 의 {{ }} 칸을 채운 보고서를 결과 폴더에 만들어 줘. 계산 과정을 설명해 줘.
```
```
주차를 실행할 때 고를 수 있게 바꿔 줘.
```
