## 💡 새로 배운 개념

- **내 작업이 지나가는 4곳:** 작업 폴더 → 저장 대기 상자(`add`) → 내 컴퓨터 저장소(`commit`) → GitHub(`push`)
- **커밋 메모가 이름표다.** 나중에 "이 세이브가 뭐였지?" 할 때 본다.
- **실수를 지우는 게 아니라, 고친 기록을 하나 더 남긴다.** 중복 줄이 생겼을 때 `git diff`로 차이를 보고 "중복 줄 정리" 커밋을 새로 만들었다.
- **연습 모드(브랜치)에서 바꾼 건 원본에 안 보인다.** 합쳐야(merge) 들어온다.
- **올리기 전에 꼭 확인할 것:** 비밀번호·API 키·개인정보가 없는지. `.gitignore`로 미리 막아 둔다.
- 처음 한 번만 하는 것: `git init`, `gh repo create`. 그다음부터는 `git push`만 하면 된다.

## 📝 포트폴리오 한 줄

- **문제:** 작업 기록이 없어 실수하면 되돌릴 수 없고, 한 일을 남에게 보여 줄 방법이 없었다
- **해결:** Git으로 세이브·되돌리기·브랜치 실험을 익히고, GitHub에 실습 저장소를 만들어 기록을 쌓기 시작
- **효과:** 실수해도 몇 초 만에 복구, 실습할 때마다 "오늘 기록 남겨 줘" 한마디로 학습일지 작성부터 GitHub 업로드까지 자동으로

## 💬 느낀 점

- 혼자 명령어를 치라고 하면 아직 못 할 것 같다. 하지만 코딩은 Claude가 맡고, 나는 **전체 그림**을 이해하는 게 중요하다는 걸 알았다.
- 저장하기, 저장 전으로 돌아가기, 연습 모드에서 실험하기, 오늘 기록 남기기. 이 네 가지를 **언제 쓸지 판단하는 것**이 내 몫이다.
