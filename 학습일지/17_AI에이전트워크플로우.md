## 💡 새로 배운 개념

- **에이전트와 워크플로우** — 역할(기획·작성·검수·수정)을 나눠 맡긴 AI 하나하나가 에이전트, 일이 넘어가는 순서가 워크플로우
- **계산은 코드, 판단은 AI** — 글자 수는 AI가 자주 틀린다. 코드가 세서 "사실"로 건네고 5번(분량)은 코드가 판정하자 1자 차이도 잡았다
- **정해진 양식(JSON)으로 답하게 하기** — 편집장이 표 모양을 지켜 답해야 다음 단계 코드가 통과/불통과를 정확히 읽는다
- **이유 먼저, 도장 나중** — 양식이 `통과 → 이유` 순서일 때 "기준 충족, 통과로 본다"고 쓰고도 ❌를 찍는 흔들림이 있었다. AI는 앞에서부터 쓰니 `이유 → 통과` 순서로 바꾸자 흔들림이 사라졌다
- **애매한 기준은 사람이 정한다** — '핵심', '근거 없는 숫자'처럼 해석이 갈리는 기준은 A/B로 정해 매뉴얼에 적어야 결과가 일정하다
- **되돌이 고리와 안전장치** — 고친 글도 다시 검수해야 하고, 무한 반복(시간·요금)을 막으려면 최대 횟수를 정해 사람에게 넘긴다
- **동시에 일 시키기** — `ThreadPoolExecutor`로 5팀이 동시에 일하면 4~5분 걸릴 일이 약 1분
- **사람 요청과 규칙의 충돌** — 사장님 요청으로 제목이 28자가 되자 편집장 메모를 따르던 작가가 요청을 지워 버렸다. "사장님 요청은 꼭 살려 둬"를 고리 안에 계속 넘겨 해결
- **서브에이전트** — `.claude/agents/`에 직원 등록증을 두면 Claude Code가 새 세션에서 읽어 직원으로 쓴다. 순서를 코드 대신 말(지휘서)로 정하니 고치기 쉽지만, 매번 똑같이 움직이는 보장은 코드가 더 강하다
- 터미널: 한글 자판에서 `y`를 누르면 `ㅛ`가 된다 / ▶ 버튼이 새 탭(실습키트 폴더)에서 열릴 수 있다 → `cd "$(git rev-parse --show-toplevel)/17_..." && 명령`으로 어디서든 같은 방에 들어가기

## 📝 포트폴리오 한 줄

- **문제:** 글 하나를 쓰려면 기획·초안·검수·수정을 사람이 차례로 하고, 검수 기준(제목 길이·분량·근거 없는 숫자 등)을 눈으로 하나하나 확인해야 했다
- **해결:** 기획자·작가·편집장 AI 에이전트로 단계를 나누고 자동으로 이었다. 검수 불통과면 최대 2번 고쳐 다시 검수하고, 글자 수는 코드가 판정하며, 발행 전 사람 승인·반려 단계와 단계별 시간·비용 기록, Claude Code 서브에이전트 버전까지 만들었다
- **효과:** 주제 5개를 약 1분, 글 1편당 약 130원에 처리하고 5편 모두 검수 6개 항목 통과. 수정·검수 기록이 CSV로 남아 어디서 자주 걸리는지 숫자로 확인할 수 있다

## 💬 느낀 점 (직접 작성)

> 사용자가 들려준 생각을 바탕으로 Claude가 문장을 다듬고 내용을 보탠 **초안**이다.

**이번에 내가 한 것**
- Claude Code에서 에이전트를 만들어 분야별 '직원'을 둘 수 있다는 이야기를 듣기만 했는데, 오늘 직접 기획자·작가·편집장을 만들어 보니 구체적인 방법을 알게 됐다. 생각보다 어렵지 않았다. 직원 등록증(`.claude/agents/`)에 역할을 글로 적어 두고, 바이브코딩답게 **말로 시키기만 하면** 됐다.
- 다만 말로 시키더라도 **기준은 내가 정해야** 한다는 것도 배웠다. '근거 없는 숫자', '첫 3문장 안에 핵심'처럼 애매한 기준을 A/B로 정하자 결과가 흔들리지 않았다. 글자 수처럼 정확해야 하는 일은 AI가 아니라 코드에 맡기니 1자 차이까지 잡아냈다.
- 마지막 발행 버튼은 사람이 누르게 했다. AI가 통과를 줘도 내가 확인하고, 반려하면 내 메모가 다시 작가에게 수정 지시로 들어가는 구조가 마음에 들었다.

**앞으로 이렇게 써 보고 싶다**
- 정말 **Claude Code 하나로 작은 회사 하나를 꾸릴 수 있겠다**는 생각이 들었다. 1인 사업이라면 'CS 팀(정책 찾기 → 답장 초안 → 규정 검수 → 내 승인)', '콘텐츠 팀(상품 소개글·블로그 글)', '보고 팀(매출·리뷰 요약)'처럼 업무마다 직원을 만들어 둘 수 있다.
- 처음부터 만들 때는 프롬프트를 외울 필요 없이 **하고 싶은 일, 대략의 단계, 중요하게 여기는 점**만 말하고 "나머지는 네가 제안하고, 애매한 건 물어봐 줘"라고 하면 된다.
- 매일 반복하는 일은 파이썬 방식으로 만들어 14번처럼 자동 예약하고, 가끔 하는 일은 서브에이전트에게 말로 시키는 식으로 나눠 쓰고 싶다. 나중에는 직원들이 일하는 모습을 별도 창에 귀여운 애니메이션으로 띄워 보고 싶다.
