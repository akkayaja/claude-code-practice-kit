## 🔢 결과 숫자 (내 눈으로 검증한 것)

- 파일 6개 → 합친 결과 **719줄**
- 빈 행 **1줄**, 중복 행 **3줄** 삭제 → 최종 **715줄**
- 지점은 정확히 **5개**: 강남점, 광주상무점, 대전둔산점, 부산서면점, 홍대점
- 상반기 전체 매출 **155,203,500원** — 원본 합계와 요약표 총합계가 **일치**
- 지점별 1위는 부산서면점(34,460,300원, 22.2%), 가장 낮은 곳은 홍대점(24,032,900원, 15.5%)
- 차트가 가리키는 칸의 숫자와 요약표 숫자 **5개 지점 모두 일치**

## 💡 새로 배운 개념

- `pd.read_excel` / `pd.concat` — 엑셀을 표로 읽고, 여러 표를 위아래로 이어 붙이기
- **정리 순서가 중요하다** — 오타·날짜를 먼저 통일해야 '강남 점'과 '강남점' 같은 *숨은 중복*까지 잡힌다
- `dropna(how="all")` — 모든 칸이 빈 줄만 지우기
- `duplicated()` → 지울 줄을 **먼저 화면에 보여 주고** `drop_duplicates()`로 지우기 (지우기 전에 눈으로 확인하는 습관)
- `pivot_table` — 엑셀의 피벗 테이블과 같은 기능, `margins=True`로 합계 줄·열 추가
- `groupby` + `nlargest(3)` — 묶어서 더한 뒤 큰 것 3개 뽑기
- openpyxl 차트는 숫자를 복사하는 게 아니라 **칸을 가리켜서** 그린다 → 표가 바뀌면 차트도 바뀜
- 파이썬 변수 이름은 숫자로 시작할 수 없다 (`4등매출` ❌ → `네번째매출` ✅)
- 검증 코드를 스크립트 안에 넣어 두면, 다시 실행할 때마다 숫자가 맞는지 자동으로 확인된다

## 📝 포트폴리오 한 줄

- **문제:** 매달 지점별 엑셀 6개를 손으로 합치고, 오타·날짜 형식·중복을 하나하나 고쳐야 했다
- **해결:** 파이썬(pandas) 스크립트로 취합 → 정리 → 지점별·월별 합계 → TOP 3 → 차트까지 한 번에 처리하고, 합계 검증까지 자동화
- **효과:** 수작업 취합 → 명령어 한 줄로 몇 초 만에 완료, 새 달 파일은 `data` 폴더에 넣기만 하면 자동 포함

## 💬 느낀 점 (직접 작성)

- 엑셀 자동화의 흐름이 이제 보인다. ① 월별 엑셀 파일을 하나로 취합하고 → ② 잘못된 것·중복된 것을 고치고 → ③ 취합 파일로 매출 합계표를 만들고 → ④ 내가 원하는 조건(TOP 3)에 맞는 데이터를 뽑고 → ⑤ 차트까지 넣는다.
- ②번 정리를 먼저 해야 '강남 점'과 '강남점' 같은 숨은 중복까지 잡힌다는 것, 순서가 중요하다는 걸 배웠다.
