## 🔢 결과 숫자 (내 눈으로 검증한 것)

- 신청 **60건**
- 과목별: AI 활용 보고서 작성 **25** / 노션 업무관리 **22** / 엑셀 자동화 기초 **13** = 60
- 일정별: 12/2(화) **27** / 12/4(목) **16** / 12/6(토) **17** = 60
- 개인정보 동의 **35** + 미동의 **25** = 60 (다른 방법으로 따로 세어도 같음)
  - 동의자만: AI 보고서 16 / 노션 13 / 엑셀 6 = 35
- 이름이 겹치는 경우 **5개 이름**(신하은 3번, 강서윤·신서연·권지민·오현우 2번) → 연락처·이메일 겹침 **0건** → 진짜 중복 **0건** (모두 동명이인)
- **파이썬 결과 = 구글 시트 '과목별 요약' 결과** (스크린샷으로 과목별·일정별 숫자 모두 일치 확인)
- 정원 15명 기준: 확정 **34** / 대기 **1** (61행 강유나, AI 보고서 동의자 중 16번째) / 제외(미동의) **25**
- 문의사항 있는 신청 **34건** (노트북 14 / 녹화본 11 / 주차 9) — 화면에 보인 2~29행의 노란 줄 13개가 정답과 모두 일치
- 트리거 시험: 테스트 신청자를 넣자 요약 숫자가 **저절로 바뀜**, 확인 메일이 **내 Gmail로 도착** (사용자 확인)

## 💡 새로 배운 개념

- **먼저 파이썬으로 연습하고 시트로 옮기기** — 정답 숫자를 미리 알고 있으면 시트 결과가 맞는지 바로 비교할 수 있다
- `csv.DictReader` + `Counter` — 설치 없이 표를 읽고 바를 정(正) 자처럼 세기
- **고유 키(key)** — 사람을 구별할 땐 이름이 아니라 연락처·이메일처럼 하나뿐인 값을 기준으로 해야 한다 (이름만 봤다면 진짜 신청자 6명을 지울 뻔)
- **어떤 기준으로 세느냐가 결과를 바꾼다** — 전체 기준이면 AI 보고서 대기 10명, 연락 가능한(동의한) 사람 기준이면 대기 1명
- **Apps Script** — 구글 시트 안에 사는 비서 로봇. 처음 실행할 때 권한 승인(고급 → 이동 → 허용)이 필요하다
- **트리거** — "시트가 바뀌면 알아서 실행해" 알람. 스크립트가 직접 바꾼 내용으로는 다시 울리지 않는다
- 시트를 **새 도화지처럼 비우고 다시 그리기** — 매번 지우고 새로 칠하니까 문의를 지우면 노란색도 자동으로 사라진다
- **자동 메일의 안전장치** — 받는 사람을 '나'로 고정, 첫 실행 때 기존 건은 발송 안 함, 한 번에 최대 3통, 입력이 끝난 줄만 발송
- `pbcopy < 파일` — 파일 내용을 통째로 클립보드에 복사 / `open data` — 폴더를 Finder로 열기
- `cd 폴더` — 터미널이 서 있는 방을 옮겨야 그 방의 파일을 실행할 수 있다

## 📝 포트폴리오 한 줄

- **문제:** 구글폼 특강 신청 60건을 손으로 세고, 미동의자·중복·정원 초과·문의사항을 일일이 확인하고, 신청자마다 확인 메일을 따로 보내야 했다
- **해결:** 파이썬으로 집계·검증 기준을 먼저 만든 뒤, Apps Script + 트리거로 과목별 요약 · 정원 초과 '대기' 표시 · 문의 행 강조 · 확인 메일 발송을 한 번에 자동화
- **효과:** 신청이 들어오면 사람이 손대지 않아도 몇 초 안에 요약표 갱신 + 상태 표시 + 확인 메일까지 끝 (수작업 약 1시간 → 자동)

## 💬 느낀 점 (직접 작성)

- 오늘은 구글폼으로 신청을 받고 관리하는 전 과정을 배웠다. 신청이 들어오면 과목별로 요약하고, 정원이 넘으면 '대기'를, 문의가 있으면 노란색을 표시하고, 확인 메일까지 자동으로 보내는 흐름이다.
- 아직은 코드를 복사해 붙여 넣고, 트리거와 권한 승인을 내 손으로 직접 했다. 다음에는 이 과정까지 클로드코드로 자동화해서, 설정부터 운영까지 손이 덜 가는 신청 관리 시스템을 만들어 보고 싶다.
