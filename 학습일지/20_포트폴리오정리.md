## 💡 새로 배운 개념

- **포트폴리오 = 나의 메뉴판** — 기술 이름보다 '문제 → 해결 → 효과'와 숫자가 기억에 남는다. 쓰이는 곳: 1인 사업 외주·제안, 면접, 몇 달 뒤의 나에게 보여 주는 지도
- **대표 3개 + 전체 목록** — 다 크게 보여 주면 지친다. 관심사(1인 사업 CS·콘텐츠)에 맞는 3개를 크게, 나머지는 "이런 것도 돼요" 목록으로
- **모르는 숫자는 빈칸으로** — '전' 시간을 재지 않았으면 "재지 않았다"고 쓴다. 제안서에서는 `[직접 측정 필요]` + 측정 방법. 16번 챗봇의 "문서에 없어요"와 같은 원칙
- **흩어진 기록을 코드로 모으기** — 학습일지 형식을 지켜 왔기 때문에 스크립트 하나로 20개를 모을 수 있었다 (형식 = 나중에 기계가 읽을 수 있는 약속)
- **제출 전 점검기** — 양식 칸·숫자·민감 정보(경로·이메일·키)를 코드로 확인
- **배포 확인은 지문(SHA)으로** — 접속 200 + 내 파일과 올라간 파일의 지문이 같으면 그대로 올라간 것
- **양방향 연결** — 사이트 → GitHub, GitHub(저장소 About·프로필 Website) → 사이트
- **권한(scope)** — 같은 GitHub 열쇠라도 저장소 권한(`repo`)과 프로필 권한(`user`)은 따로다. 권한 추가는 본인 확인이 필요해 사용자가 직접 승인
- **도구 재사용** — 17번 글자수세기로 블로그 글을 검수하고, 06번 가상환경으로 그래프를 그렸다. 예전에 만든 것이 다음 일의 부품이 된다
- 터미널: 한/영 키가 영어면 "a안"이 `adks`로 입력된다

- **문제:** 실습 20개를 만들었지만 기록이 폴더와 일지에 흩어져 있어, 남에게 "무엇을 할 수 있는지"를 한 번에 보여 줄 방법이 없었다

- **효과:** 링크 하나(https://ai-automation-portfolio-practice.vercel.app)로 자동화 20개를 휴대폰에서도 보여 줄 수 있게 됨. 사례 3/3 점검 통과, 지어낸 숫자 0개(재지 않은 숫자는 빈칸 10곳으로 표시)

## 💬 느낀 점 (직접 작성)

> 사용자가 "알아서 써 달라"고 해서 Claude가 오늘 한 일을 바탕으로 쓴 **초안**이다. 내 생각과 다른 곳은 고쳐 쓴다.

**이번에 내가 한 것**
- 01번부터 하나씩 만들 때는 몰랐는데, 일지 20개에서 한 줄씩 모아 보니 엑셀 정리에서 시작해 AI 직원 팀까지 꽤 먼 길을 왔다는 게 한눈에 보였다. 학습일지를 같은 형식으로 꾸준히 써 둔 덕분에 스크립트 하나로 20개를 몇 초 만에 모을 수 있었다.
- 대표 사례, 그래프, 웹사이트 구성, 제안서 주제, 블로그 방식을 모두 A안으로 골랐다. 고르고 보니 전부 **1인 사업에서 AI로 CS·콘텐츠 팀을 꾸리는 이야기** 한 줄로 이어졌다. 내가 무엇에 관심이 있는지가 포트폴리오에 그대로 드러났다.
- 사람이 직접 하면 몇 분 걸리는지는 재 본 적이 없어서 "재지 않았다"고 적고, 제안서에는 `[직접 측정 필요]` 빈칸을 10곳 남겼다. 그럴듯한 숫자를 채우고 싶은 마음도 들었지만, 16번 챗봇에게 "문서에 없으면 없다고 말해"라고 시킨 것처럼 나도 같은 원칙을 지켰다.
- 프로필 링크는 처음에 직접 설정하는 단계였는데 Claude에게 맡겼다. 열쇠에 프로필 권한이 없어서, 본인 확인만 내가 하고 나머지는 Claude가 처리했다. 무엇은 내가 해야 하고 무엇은 맡길 수 있는지 구분하게 됐다.

**포트폴리오가 어디에 쓰이는지**
- 19번에서는 문서화가 왜 필요한지 잘 와닿지 않았다. 오늘 설명서와 학습일지가 그대로 포트폴리오 재료가 되는 걸 보니 연결이 됐다. 기록은 남에게 보여 줄 때 비로소 쓸모가 생긴다.
- 링크 하나면 휴대폰에서 바로 열린다. 외주를 제안할 때 "이런 거 할 수 있어요"라고 말로 설명하는 대신 이 주소를 보내면 된다.

**앞으로 이렇게 써 보고 싶다**
- **CS 자동화 제안서를 실제로 해 보기:** 1주 차처럼 지금 방식으로 시간을 먼저 재서 빈칸을 채우고, 15·16·14번 도구를 조립해 4주 시범을 돌려 보고 싶다.

- **포트폴리오 계속 키우기:** 새로 만드는 것(고객 CS 챗봇, 날씨 MCP 등)이 생기면 학습일지 → 사례 → 웹사이트 카드 순서로 하나씩 더하고, 실제 화면 캡처와 '전' 시간 측정으로 🔺 두 칸도 채우겠다.
