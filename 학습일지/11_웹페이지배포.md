## 🔢 결과 숫자 (직접 확인한 것)

- 페이지 구성: 메뉴 카드 **4개**, 영업시간 **3줄**(평일·주말·휴무)
- 휴대폰 폭(375px)에서 가로 넘침 **0** → 카드가 한 줄에 1개씩 쌓임
- 첫 커밋 `ad4467e`: **263줄** 추가 (기본 페이지)
- 둘째 커밋 `c5ecd08`: **124줄 추가, 3줄 수정** (다크모드 + 문의 폼) → 최종 **384줄**
- 배포 주소 접속 결과 **200**(정상), 로그인 없이 누구나 열람 가능
- 배포된 파일과 내 컴퓨터 파일의 지문(SHA) **일치** (`8f7a0ae…`)
- 공개 전 개인정보 점검: 파일·커밋 기록 **15개 + 2개**에서 실명·개인 이메일·직업 **0건** (커밋 이메일은 GitHub 가림 주소)

## 💡 새로 배운 개념

- **HTML / CSS / 자바스크립트의 역할 나누기** — 내용(전단지) / 꾸미기(인테리어) / 동작(스위치)
- `<meta name="viewport">` 한 줄이 없으면 휴대폰에서 페이지가 아주 작게 보인다
- `@media (max-width: 640px)` — "화면이 좁으면 이렇게 바꿔"라는 규칙. 2칸 → 1칸
- **색을 변수로 모아 두면**(`--bg`, `--text`…) 다크모드는 색상표만 갈아 끼우면 된다
- `localStorage` — 브라우저에 작은 메모를 남겨서 다음에 열어도 고른 모드를 기억
- 폼의 `required` — 빈칸이면 브라우저가 알아서 막아 준다
- **공개 사이트에는 개인 이메일을 넣지 않는다** — 문의 폼을 실제로 받으려면 따로 받는 곳(예: 04번 구글 시트)이 필요
- **배포(Vercel)** — 파일을 올리면 `○○.vercel.app` 주소가 생긴다. 고치면 다시 배포해야 반영된다
- 터미널이 어느 폴더에 있는지에 따라 `open index.html` / `open "11_웹페이지배포/index.html"`처럼 주소를 다르게 써야 한다
- ↑ 키로 지난 `git commit`을 다시 실행해도 `nothing to commit` → 이미 세이브됐다는 확인일 뿐 문제 없다
