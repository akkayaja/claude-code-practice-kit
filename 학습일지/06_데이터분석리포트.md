## 💡 새로 배운 개념

- **분석은 질문에서 시작한다**: 질문 → 계산법 정하기 → 표·그래프 → 잘못 읽기 쉬운 점 확인 → 한 줄 결론
- **pandas**: `read_csv`로 표 읽기, `groupby`로 묶어서 합계·평균, `pivot_table`로 연도 × 분기 표, `diff`·`pct_change`로 전 달 대비 변화 계산
- **matplotlib**: 막대·가로막대·꺾은선 그래프, 한글 글꼴(`AppleGothic`) 설정, 그래프 2개 나란히(`subplots`)
- **비율로 비교해야 공평하다**: 큰 지역은 폐업 수도 많으니 폐업 ÷ 점포수(폐업률)로 비교
- **%와 %p는 다르다**: 11.61% − 9.98% = 1.63%p
- **축이 어디서 시작하는지 먼저 보기**: 축을 자르면 작은 차이도 크게 보인다 (질문 1은 9%부터, 질문 2는 0부터)
- **"뚜렷한 답이 없다"도 결론이다**: 폐업은 특정 분기에 몰리지 않았다
- **기준에 따라 1등이 달라진다**: 증가 수는 큰 지역이, 증가율은 출발점이 작은 지역이 유리하다
- **공공데이터는 한글 방식이 다를 수 있다**: `encoding="cp949"`로 읽어야 한글이 안 깨진다
- **빈칸 0개 ≠ 완벽한 데이터**: 줄 자체가 빠진 날짜는 따로 찾아야 한다
- **극적인 숫자는 먼저 의심하기**: 진짜 변화인지, 세는 방법(집계 기준)이 바뀐 건지
- **들쭉날쭉 지수(표준편차)**: 숫자가 클수록 들쭉날쭉하고, 0에 가까울수록 일정하다
- **추세선과 예측**: `np.polyfit`으로 점들 사이를 가장 잘 지나는 직선을 긋고 앞으로 늘린다. 예측은 답보다 **가정을 함께 말하는 것**이 중요하다
- **HTML 리포트 한 파일로 공유**: 그림을 base64로 HTML 안에 넣으면 파일 하나만 보내도 그래프까지 보인다
- **출처 밝히기**: 실제 데이터를 쓸 땐 제공기관과 링크, 이용허락범위를 리포트에 적는다

## 📝 포트폴리오 한 줄

- **문제:** 지역·분기별 카페 데이터와 실제 공공데이터를 보고 "어디가 위험하고, 어디가 성장하는지"를 판단하려면 엑셀로 일일이 계산하고 그래프를 그려야 했고, 데이터의 구멍이나 이상한 값을 놓치기 쉬웠다
- **해결:** 파이썬(pandas, matplotlib)으로 데이터 점검 → 질문별 표·그래프 → 한 줄 결론 → HTML 리포트까지 자동으로 만들고, 실제 공공데이터에서는 빠진 달·튀는 값을 찾아 믿을 수 있는 구간만 골라 분석과 예측을 했다
- **효과:** 질문 3개짜리 분석 리포트를 명령어 몇 줄로 몇 초 만에 다시 만들 수 있고, 리포트 파일 하나로 그래프·결론·주의할 점까지 공유 가능
