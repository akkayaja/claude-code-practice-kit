## 🔢 결과 숫자 (내 눈으로 검증한 것)

- PDF **8장** 모두 추출 성공
- 정답 CSV와 비교: **56칸**(8장 × 7칸) 중 틀린 칸 **0칸** → **100% 일치**
- 전체 공급가액 **7,232,000원** / 부가세 **723,200원** / 합계 **7,955,200원**
- 금액 검증: 공급가액 + 부가세 = 합계 **8/8**, 부가세 = 공급가액의 10% **8/8**
- 공급자별 합계 (4곳)
  - 스마트IT솔루션 2건 **2,825,900원** (1위)
  - (주)한빛문구 3건 **2,193,950원** (건수는 가장 많음)
  - 대한사무기기 1건 **1,524,600원**
  - 새롬오피스 2건 **1,410,750원**
- 공급자별 합계를 모두 더해도 **7,955,200원**이라 빠진 건이 없음
- 품목 상세: 품목 줄 **23개**, 수량 × 단가 = 금액과 품목 합 = 공급가액 검사에서 **문제 0건**

## 💡 새로 배운 개념

- **`pdfplumber`**: PDF를 열어 `extract_text()`로 글자만 뽑아낸다
- **먼저 눈으로 보고, 그다음 규칙을 정한다**: PDF 글자를 출력해 보니 `문서번호: INV-2026-101`처럼 `이름: 값` 모양이어서, "이름표 뒤의 값을 가져와"라는 규칙을 세울 수 있었다
- **정규식(`re`)**: 글자 속에서 정해진 모양(패턴)에 맞는 부분을 찾는 도구. 예) `^공급가액:\s*(.+)$`
- **글자 → 숫자 바꾸기**: `307,500원`은 계산할 수 없는 글자라서, 쉼표와 `원`을 지워 `307500`으로 바꿔야 한다
- **이름이 다를 수 있다**: 정답 파일은 `합계`, PDF에는 `합계금액`으로 적혀 있었다
- **끝에서부터 떼어 내기**: `A4 복사용지 12 28,000 336,000`처럼 품목 이름에 띄어쓰기가 있어도, 줄 끝의 숫자 3개를 먼저 떼어 내면 남은 앞부분이 품목 이름이 된다
- **openpyxl로 엑셀 꾸미기**: 제목 줄 굵게·색칠(`Font`, `PatternFill`), 쉼표 표시(`number_format = "#,##0"`), 시트 추가(`create_sheet`)
- **채점 코드 만들기**: 내 결과와 정답을 한 칸씩 비교하면 눈으로 확인하는 것보다 빠르고 정확하다
- **검증은 여러 겹으로**: 합계 검증 → 공급자별로 나눴다가 다시 더하기 → 품목 합과 공급가액 비교. 숫자가 서로 맞물리면 추출이 맞았다고 믿을 수 있다
- **가상환경은 실습마다 따로**: `uv venv --python 3.12`로 공구함을 만들고 `uv pip install`로 공구를 넣는다

## 📝 포트폴리오 한 줄

- **문제:** 거래명세서 PDF를 한 장씩 열어 문서번호·날짜·공급자·금액을 엑셀에 손으로 옮겨 적어야 했고, 옮겨 적다 틀려도 알아채기 어려웠다
- **해결:** 파이썬(pdfplumber)으로 PDF 8장에서 필요한 값과 품목 표를 자동으로 뽑아 엑셀에 저장하고, 공급가액 + 부가세 = 합계·부가세 10%·품목 합 검증과 공급자별 집계까지 자동화
- **효과:** 수작업 입력 → 명령어 한 줄로 몇 초 만에 완료, 정답과 56칸 100% 일치, 금액 오류가 있으면 ❌로 바로 표시

## 💬 느낀 점 (직접 작성)

- PDF에 들어 있는 내용을 엑셀 같은 문서 형식으로 옮겨 저장할 수 있다는 걸 알게 됐다.
- 무엇보다 "공급가액 + 부가세가 합계와 맞는지 검증해 줘"처럼 **내가 필요한 것을 말로 요청하면**, 원하는 값만 뽑아내고 자동으로 검증까지 할 수 있다는 점이 인상 깊었다.
