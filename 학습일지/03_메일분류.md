## 🔢 결과 숫자 (내 눈으로 검증한 것)

- 메일 **20통** 모두 표에 나옴, 첨부 있는 메일 **4통**(mail_01, 04, 05, 11) — README의 "첨부파일 4개"와 **일치**
- 첫 규칙 정확도 **18/20 = 90%**
  - mail_06 `[세금계산서] 복합기 렌탈료` → 본문의 "안내"에 걸려 사내공지로 감 (정답: 청구서)
  - mail_14 `1억원 당첨되셨습니다` → 어떤 규칙에도 안 걸려 기본칸(고객문의)으로 감 (정답: 스팸)
- 스팸에 `당첨`, 청구서에 `세금계산서` 추가 → 다시 채점 **20/20 = 100%**, 다른 18통은 그대로
- 고친 뒤 칸별 개수: 스팸 3 / 견적요청 4 / 청구서 4 / 사내공지 4 / 고객문의 5 = **20통**
- 첨부파일 **4개** 저장 — `견적요청서.csv`를 열어 보니 "사무용 의자, 50, 120000"으로 본문 내용과 **일치**
- 청구서 합계 **3,476,000원** (3,300,000 + 55,000 + 88,000 + 33,000) — 손으로 더한 값과 **일치**
  - mail_04 첨부(3,000,000 + 300,000 = 3,300,000원), mail_05 첨부(55,000원)도 본문 금액과 **일치**
- 답장 초안 **5개** (환불·배송·사용법·회원탈퇴·교환), "기타"로 빠진 메일 **0개**
- AI 분류: 힌트 있는 지시문 **20/20 = 100%**, 힌트를 뺀 지시문으로 재대결해도 **20/20 = 100%**

## 💡 새로 배운 개념

- `.eml` = 메일 한 통을 통째로 담은 봉투. 한글 제목·본문·첨부는 **base64**로 포장돼 있어서 사람이 직접은 못 읽는다 → `email` 모듈의 `BytesParser(policy=policy.default)`가 포장을 풀어 준다
- `iter_attachments()` + `get_payload(decode=True)` — 메일 안의 첨부만 골라 진짜 파일 내용으로 꺼내기
- **규칙의 검사 순서가 결과를 바꾼다** — 위에서부터 검사해 처음 맞는 칸에 넣으므로, "견적 문의"처럼 두 칸에 걸치는 메일은 순서로 갈 곳이 정해진다
- 규칙을 **파일 맨 위에 모아 두면** 코드를 몰라도 그 부분만 고쳐서 결과를 바꿀 수 있다
- 다시 실행할 때 예전 결과가 섞이지 않도록 결과 폴더를 **비우고 시작**하기 (`shutil.rmtree`)
- **정규표현식** (`re`) — 정확한 단어가 아니라 "숫자+쉼표+원" 같은 **모양**으로 찾기 (금액, 주문번호)
- **저장을 해야 반영된다** — 프로그램은 화면이 아니라 저장된 파일대로만 동작한다. 맥의 `nano`(pico)는 한글 입력이 잘 안 돼서 VS Code로 고쳤다
- `grep -n` — 파일에서 특정 단어가 있는 줄을 찾아 저장됐는지 확인
- `killall nano` — 숨어서 남아 있던 프로그램 한꺼번에 끄기
- **가상환경(.venv)** — 이 폴더 전용 파이썬 상자. `uv`로 파이썬 3.12와 도구를 원래 파이썬과 따로 설치
- **API 키는 `.env`에, `.env`는 `.gitignore`에** — 키는 채팅·스크린샷·GitHub 어디에도 올리지 않는다. `git check-ignore`로 무시되는지 확인
- **Claude API 호출** — `anthropic.Anthropic()`로 연결 → 지시문(system)과 메일을 보내고 칸 이름 한 단어로 대답 받기. 쉬운 일은 `effort: low`로 요금 절약
- **규칙 vs AI** — 규칙은 단어를 보고(무료·빠름·늘 같은 답), AI는 뜻을 이해한다(처음 보는 표현도 판단, 요금·시간이 듦). 실무에서는 확실한 건 규칙, 애매한 건 AI로 섞어 쓸 수 있다
- 공정하게 비교하려면 **채점하며 알게 된 힌트를 AI 지시문에 넣지 않아야** 한다

## 📝 포트폴리오 한 줄

- **문제:** 매일 쏟아지는 업무 메일을 하나씩 열어 읽고, 견적·청구서·고객문의·공지·스팸으로 나누고, 첨부파일을 따로 저장하고, 청구 금액을 더하고, 고객 답장을 써야 했다
- **해결:** 파이썬으로 메일 파일을 읽어 키워드 규칙대로 폴더 분류 → 첨부 저장 → 청구서 금액 합계 → 고객문의 답장 초안까지 자동화하고, 같은 분류를 Claude API에도 맡겨 정답과 비교 채점
- **효과:** 메일 20통 분류·첨부 정리·금액 합계·답장 초안을 명령어 몇 줄로 몇 초 만에 완료, 정확도 90% → 규칙 수정 후 100%, AI 분류도 힌트 없이 100%

## 💬 느낀 점 (직접 작성)

- 오늘은 메일을 자동으로 분류하는 방법을 배웠다. 키워드 조건식은 처음 보는 표현이 나오면 사람이 규칙을 계속 고쳐 줘야 했지만, API로 AI에게 맡기니 힌트 없이도 뜻을 이해해 모두 맞혔다. 사람 손이 덜 가는 진짜 자동화에는 API 쪽이 더 낫다고 느꼈다.
- 메일을 읽고 → 나누고 → 첨부를 모으고 → 금액을 더하고 → 답장 초안까지 쓰는 흐름을 알게 되니, 이걸 응용하면 앞으로 많은 업무를 자동화할 수 있을 것 같다.
