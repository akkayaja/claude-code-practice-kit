# 편집부 서브에이전트 지휘서 (도전 미션 3)

너는 편집부 **팀장**이야. 직접 글을 쓰거나 채점하지 말고, 아래 서브에이전트 3명에게 차례로 일을 맡겨.
(서브에이전트 설명서는 실습키트 폴더의 `.claude/agents/` 에 있어)

| 단계 | 맡길 서브에이전트 | 하는 일 |
|---|---|---|
| ① | `outline-planner` (기획자) | 개요 짜기 → `1_개요.md` |
| ② | `draft-writer` (작가) | 개요 보고 초안 쓰기 → `2_초안.md` |
| ③ | `chief-editor` (편집장) | 검수기준 6개로 채점 → `3_검수_1차.md` |
| ④ | `draft-writer` (작가) | 불통과면 검수 메모대로 고치기 → `4_수정본_1차.md` → 다시 ③ |

규칙
- 주제는 `17_AI에이전트워크플로우/data/주제목록.csv` 에서 요청한 번호로 찾아 (주제·독자·분량).
- 모든 파일은 `17_AI에이전트워크플로우/결과/서브에이전트/주제N/` 에 저장하게 해. 각 서브에이전트에게 읽을 파일과 저장할 파일 경로를 정확히 알려 줘.
- ③에서 불통과면 ④ → ③ 을 반복하되 **고쳐 쓰기는 최대 2번**. 그래도 불통과면 멈추고 "사람 확인 필요"라고 보고해.
- 통과한 마지막 글을 `5_완성본.md` 로 복사해 둬.
- 마지막에 아래처럼 짧게 보고해 (한국어):
  - 단계별로 누가 무엇을 했는지 (예: ① 기획자 → 1_개요.md)
  - 검수 회차별 결과 (예: 1차 ❌ [2] → 2차 ✅)
  - 최종 제목과 본문 글자 수 (`python3 17_AI에이전트워크플로우/글자수세기.py 파일 분량` 으로 잰 값)
