# 17. AI 에이전트로 여러 단계 업무 자동화

> **얻는 능력:** 사람이 하던 업무 프로세스를 단계별 AI 작업으로 옮기는 능력

**왜 배우나요?** '자료조사 → 초안 작성 → 검수 → 수정'처럼 여러 단계를 AI가 역할을 나눠 처리하게 만드는 것, 지금 가장 몸값이 오르는 기술이에요.

## 📁 들어 있는 파일
- `data/주제목록.csv` – 글 주제 5개 (독자·분량 지정)
- `data/검수기준.md` – 검수 담당 AI가 사용할 체크리스트

## 🧭 기본 미션 (순서대로)
1. 사람이 글 하나를 쓸 때의 단계를 종이에 적어 본다 (예: 개요 → 초안 → 검수 → 수정)
2. 주제 1개로 단계마다 따로 AI에게 시켜 본다 (수동으로)
3. 단계를 자동으로 이어 주는 스크립트를 만든다
4. 검수 단계가 '불통과'를 주면 수정 단계로 돌아가게 만든다 (최대 2회)
5. 5개 주제를 한 번에 돌리고 결과와 검수 기록을 저장한다

## 🔥 도전 미션 (기본을 끝냈다면)
- Claude Code의 서브에이전트 기능으로 같은 흐름 만들어 보기
- 단계별 소요 시간·비용 기록하기
- 사람 승인 단계 넣기 (발행 전 확인)

막히면 아래 문장을 그대로 복사해서 써도 돼요. 단, **먼저 결과를 직접 실행해 보고, 코드에서 모르는 줄은 "이 줄이 뭐 하는 거야?"라고 꼭 물어보세요.** 그래야 실력이 남아요.

```
```

```
```

