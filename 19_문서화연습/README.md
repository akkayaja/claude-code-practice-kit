# 19. 만든 것을 문서화하기

> **얻는 능력:** 내가 만든 걸 남이 이해하고 쓸 수 있게 설명하는 능력

**왜 배우나요?** 채용 담당자와 고객은 코드를 읽지 않아요. README 하나로 '이 사람은 일을 끝까지 정리하는구나'가 보입니다.

## 📁 들어 있는 파일
- `undocumented/tool.py` – 이름도 설명도 엉망인 스크립트 (뭐 하는 건지 직접 알아내야 함)

## 🧭 기본 미션 (순서대로)
1. tool.py 를 Claude Code에 해석시키기 전에, 먼저 직접 읽고 뭘 하는지 추측해 적는다
2. Claude Code로 해석해 내 추측과 비교한다
3. 08번 데이터(`../08_대시보드/data/일별_채널별_매출_2025.csv`)로 실제 실행해 본다
4. 함수·변수 이름을 알아보기 쉽게 바꾸고 주석을 단다 (리팩터링)
5. README.md를 쓴다: 무엇을 하나 / 설치 / 사용법(예시 명령) / 결과 예시 / 주의사항

## 🔥 도전 미션 (기본을 끝냈다면)

## 💬 Claude Code에 이렇게 말해 보세요
막히면 아래 문장을 그대로 복사해서 써도 돼요. 단, **먼저 결과를 직접 실행해 보고, 코드에서 모르는 줄은 "이 줄이 뭐 하는 거야?"라고 꼭 물어보세요.** 그래야 실력이 남아요.

```
undocumented/tool.py 가 뭘 하는지 내가 이렇게 추측했어: ... 맞는지 확인하고 틀린 부분을 알려 줘.
```
```
이 스크립트의 함수와 변수 이름을 읽기 쉽게 바꾸고, 초보자가 따라 할 수 있는 README.md를 써 줘. 사용 예시 명령어도 넣어 줘.
```
