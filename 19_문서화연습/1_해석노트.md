# tool.py 해석 노트

## 1. 내 추측 (Claude에게 묻기 전)

> 날짜별로 매출이랑 주문수 더해서 객단가 구하는 거 같아

## 2. Claude 해석과 비교

| 부분 | 내 추측 | 실제 | 판정 |
|---|---|---|---|
| 무엇을 더하나 | 매출, 주문수 | `매출액`, `주문수` 칸 | ✅ 맞음 |
| 무엇을 계산하나 | 객단가 | 매출 ÷ 주문 (반올림, 주문 0이면 0) | ✅ 맞음 |
| 어떤 단위로 묶나 | 날짜별 | **월별** (`2025-01-01`의 앞 7글자 `2025-01`만 씀) | 🔶 거의 맞음 |
| 채널 고르기 | (못 찾음) | 세 번째 값에 채널 이름을 주면 **그 채널만** 계산 | ➕ 새로 알게 됨 |
| 결과는 어디로 | (못 찾음) | 화면이 아니라 **CSV 파일**로 저장 (`월, 매출, 주문, 객단가`) | ➕ 새로 알게 됨 |
| 값을 덜 넣으면 | (못 찾음) | `?` 한 글자만 찍고 멈춤 → 왜 틀렸는지 알려 주지 않음 | ➕ 새로 알게 됨 |

## 3. 줄별 해석

| 줄 | 하는 일 |
|---|---|
| 4 `def f(a, b=None)` | `a` = 읽을 CSV 파일, `b` = 고를 채널 (없어도 됨) |
| 5 `defaultdict(lambda: [0, 0])` | 월마다 `[매출 합계, 주문 합계]` 빈 칸 두 개짜리 장부를 자동으로 펼침 |
| 8~9 | 채널을 골랐는데 다른 채널이면 건너뜀 |
| 10 `row["날짜"][:7]` | 날짜에서 '연-월'만 잘라 묶음 이름으로 씀 |
| 11 | 그 달 장부에 매출액·주문수를 더함 |
| 14 `def g(r, o)` | `r` = 월별 장부, `o` = 저장할 파일 이름 |
| 18 | 월 순서대로 한 줄씩 쓰고, 객단가 = 매출 ÷ 주문 |
| 21~22 | 값이 2개보다 적으면 `?` 찍고 종료 |
| 23 | 실행 순서: `python3 tool.py 읽을파일 저장할파일 [채널]` |

## 4. 한 줄 요약
