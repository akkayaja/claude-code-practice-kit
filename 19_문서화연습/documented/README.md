# 📊 월별 매출 요약기

매일 쌓이는 **일별·채널별 매출 CSV**를 넣으면, **월마다 매출 합계 · 주문 합계 · 객단가**를 계산해 새 CSV로 저장해 주는 작은 도구예요.
채널 이름(예: `쿠팡`)을 주면 그 채널만 골라서 계산해요.

> 엑셀에서 월마다 필터 걸고 합계 내고 나누기 하던 일을 **명령어 한 줄**로 끝내요.

---

## 1. 무엇을 하나요?

```
일별·채널별 매출 (1,460줄)          월별 요약 (12줄)
┌────────────┬──────┬────┬────────┐      ┌───────┬───────────┬──────┬───────┐
│ 날짜       │ 채널 │주문│ 매출액 │  →   │ 월    │ 매출      │ 주문 │객단가 │
│ 2025-01-01 │ 쿠팡 │ 58 │1916494 │      │2025-01│197,913,475│ 5731 │ 34534 │
│ ...        │      │    │        │      │ ...   │           │      │       │
└────────────┴──────┴────┴────────┘      └───────┴───────────┴──────┴───────┘
```

| 계산 | 방법 |
|---|---|
| 월 묶기 | 날짜 `2025-01-15`의 앞 7글자 `2025-01` 이 같은 줄끼리 묶어요 |
| 매출 | 그 달 `매출액`을 모두 더해요 |
| 주문 | 그 달 `주문수`를 모두 더해요 |
| 객단가 | **매출 합계 ÷ 주문 합계** (원 단위 반올림). 하루하루 객단가의 평균이 아니에요 |

---

## 2. 설치

**따로 설치할 것이 없어요.** 파이썬 기본 기능(`csv`, `os`, `sys`)만 써요.

- 맥에는 파이썬이 이미 있어요. 터미널에서 확인:
  ```bash
  python3 --version
  ```
  (어느 폴더에서 쳐도 돼요.) `Python 3.9.6` 처럼 3.x 버전이 나오면 준비 끝이에요. (3.8 이상이면 돼요)
- 윈도우라면 [python.org](https://www.python.org/downloads/)에서 설치한 뒤, 아래 명령의 `python3`를 `python`으로 바꿔 쓰세요.

---

## 3. 사용법

**터미널에서 `19_문서화연습` 폴더로 먼저 들어가요.**
아래 명령은 터미널이 **`실습키트` 폴더**에 있을 때 돼요. 지금 어디 있는지는 `pwd`(현재 위치 보기)로 확인해요.

```bash
cd 19_문서화연습
```

> 📖 **처음 보는 말 풀이**
> - `../` = **한 단계 위 폴더**. `../08_대시보드`는 "19번 폴더에서 한 칸 올라가 08번 폴더로"라는 뜻이에요.
> - 객단가 = **주문 1건당 평균 금액**
> - 머리글 = CSV 첫 줄의 칸 이름 (`날짜,채널,주문수,매출액`)

형식:

```
python3 documented/월별매출요약.py  읽을_CSV  저장할_CSV  [채널이름]
```

| 자리 | 넣을 것 | 꼭 필요? |
|---|---|---|
| 첫 번째 | 읽을 매출 CSV 파일 경로 | ✅ |
| 두 번째 | 결과를 저장할 CSV 파일 경로 (폴더가 없으면 자동으로 만듦) | ✅ |
| 세 번째 | 고를 채널 이름 (`자사몰` / `스마트스토어` / `쿠팡` / `오프라인`) | 선택 — 비우면 전체 채널 |

### 예시 ① 전체 채널

```bash
python3 documented/월별매출요약.py ../08_대시보드/data/일별_채널별_매출_2025.csv 결과/월별_전체.csv
```

### 예시 ② 쿠팡만

```bash
python3 documented/월별매출요약.py ../08_대시보드/data/일별_채널별_매출_2025.csv 결과/월별_쿠팡.csv 쿠팡
```

### 읽을 CSV는 이렇게 생겨야 해요

첫 줄(머리글)에 아래 4개 칸 이름이 **정확히** 있어야 해요. 다른 칸(예: `방문자수`)은 있어도 괜찮아요.

```
날짜,채널,주문수,매출액
2025-01-01,자사몰,40,1152720
2025-01-01,쿠팡,58,1916494
```

## 4. 결과 예시

실행하면 화면에 이렇게 나와요:

```
✅ 저장 완료 (전체 채널, 12개월): 결과/월별_전체.csv
```

결과 파일은 **`19_문서화연습/결과/`** 폴더에 생겨요. 화면에는 "저장 완료" 한 줄만 나오니, 숫자는 파일을 열어서 봐요:

```bash
column -s, -t < 결과/월별_전체.csv
```

(`column`은 쉼표로 나뉜 칸을 표처럼 줄 맞춰 보여 줘요. 엑셀로 열어도 돼요: `open 결과/월별_전체.csv`)

저장된 `결과/월별_전체.csv` (2025년 08번 실습 데이터 기준):

| 월 | 매출 | 주문 | 객단가 |
|---|---:|---:|---:|
| 2025-01 | 197,913,475 | 5,731 | 34,534 |
| 2025-02 | 188,920,614 | 5,393 | 35,031 |
| … | … | … | … |
| 2025-11 | 248,329,079 | 7,229 | 34,352 |
| 2025-12 | 287,060,601 | 8,150 | 35,222 |

- 1년 매출 합계 **2,537,383,365원**, 주문 **72,812건** (12개월을 더한 값)
- 쿠팡만 돌리면 1년 매출 **861,384,715원**, 주문 **24,671건** (약 34%)

> 파일 안의 숫자에는 쉼표가 없어요(`197913475`). 엑셀로 열면 셀 서식으로 쉼표를 넣을 수 있어요.

## 5. 주의사항

| 상황 | 이렇게 돼요 / 이렇게 하세요 |
|---|---|
| 채널 이름 오타 (`쿠펑`, `네이버`) | ❌ 멈추고 "쓸 수 있는 채널: 스마트스토어, 오프라인, 자사몰, 쿠팡"을 알려 줘요. **띄어쓰기까지 똑같이** 써야 해요 |
| 저장할 파일이 이미 있음 | ⚠️ **물어보지 않고 덮어써요.** 남겨야 하는 결과면 이름을 바꿔 저장하세요 |
| 읽을 파일 경로가 틀림 | ❌ "읽을 파일을 찾지 못했어요"가 나와요. `cd`로 `19_문서화연습` 폴더에 들어왔는지 먼저 확인하세요 |
| 필요한 칸이 없음 | ❌ 어떤 칸이 빠졌는지 알려 주고 멈춰요 |
| 날짜 형식 | `2025-01-15`(연-월-일) 형식만 맞게 묶여요. `2025.1.15` 같은 형식은 먼저 고쳐야 해요 |
| 숫자 칸 | `주문수`·`매출액`에 쉼표(`1,000`)나 `원`이 들어 있으면 오류가 나요. 숫자만 있어야 해요 |
| 한글 깨짐 | 결과는 엑셀용 `utf-8-sig`로 저장해서 엑셀에서 바로 열어도 한글이 안 깨져요 |
| 연도가 여러 개 | 월 이름에 연도가 붙어 있어서(`2024-12`, `2025-12`) 섞이지 않아요 |
