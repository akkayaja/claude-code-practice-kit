# 05. PDF 문서에서 정보 추출

> **얻는 능력:** PDF 같은 비정형 문서에서 필요한 값을 뽑아 표로 만드는 능력

**왜 배우나요?** 거래명세서·청구서·계약서를 하나씩 열어 엑셀에 옮겨 적는 일, 정말 많죠. 이걸 자동화하는 건 회계·총무·영업지원 어디서나 통합니다.

## 📁 들어 있는 파일
- `invoices/거래명세서_01~08.pdf` – 공급자·품목·금액이 적힌 가짜 거래명세서 8장
- `정답_추출결과.csv` – 내 결과와 비교할 정답

## 🧭 기본 미션 (순서대로)
1. PDF 하나를 열어 어떤 정보가 있는지 확인한다
2. PDF에서 텍스트를 뽑아 화면에 출력해 본다
3. 문서번호·거래일자·공급자·공급가액·부가세·합계를 뽑는다
4. 8장 결과를 `결과/거래명세서_목록.xlsx`로 저장한다
5. 정답 파일과 비교해 틀린 칸이 없는지 확인한다

## 🔥 도전 미션 (기본을 끝냈다면)
- 공급자별 총 거래금액 집계
- 공급가액 + 부가세 = 합계 가 맞는지 자동 검증하기
- 품목 단위 상세 표까지 뽑기

