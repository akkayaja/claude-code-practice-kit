# 09. 웹 크롤링으로 데이터 수집

> **얻는 능력:** 웹페이지에서 원하는 정보를 자동으로 모아 오는 능력

**왜 배우나요?** 시장조사, 가격 비교, 리뷰 수집 등 '웹에서 긁어 오기'는 마케팅·기획·영업 어디서나 수요가 있어요. 실제 사이트 대신 내 컴퓨터에서 도는 연습용 쇼핑몰로 안전하게 연습합니다.

## 📁 들어 있는 파일
- `practice_site/` – 연습용 쇼핑몰 (상품 45개, 목록 3페이지 + 상품 상세 페이지)

## 🧭 기본 미션 (순서대로)
1. 터미널에서 연습 사이트를 켠다: `cd practice_site` 후 `python3 -m http.server 8080`
2. 브라우저에서 http://localhost:8080 을 열어 구조를 눈으로 본다
3. 1페이지의 상품명·카테고리·가격·평점·리뷰수를 뽑는다
4. '다음' 링크를 따라가며 3페이지 전부 수집한다
5. 결과를 `결과/상품목록.csv`로 저장한다

## 🔥 도전 미션 (기본을 끝냈다면)
- 상세 페이지까지 들어가 판매자·재고도 수집하기
- 요청 사이에 1초씩 쉬게 만들기 (예의 있는 크롤링)
- 가격이 바뀌면 알려 주는 모니터링으로 확장

