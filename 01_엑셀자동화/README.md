# 01. 엑셀 반복 업무 자동화

> **얻는 능력:** 파이썬으로 엑셀 데이터를 읽고, 정리하고, 요약하는 능력

**왜 배우나요?** 어느 회사든 '매달 엑셀 여러 개를 합쳐서 집계'하는 일이 있어요. 이걸 자동화할 줄 알면 입사 첫 주부터 티가 납니다.

## 📁 들어 있는 파일
- `data/매출_2026_01~06.xlsx` – 카페 5개 지점의 월별 매출 (일부러 오타·날짜형식 섞임·중복·빈 행을 넣어 둠)

## 🧭 기본 미션 (순서대로)
1. 엑셀 파일 하나를 열어서 눈으로 구조를 확인한다 (열 이름, 이상한 데이터 찾기)
2. Claude Code에 6개 파일을 하나로 합치는 스크립트를 만들어 달라고 한다
3. 지점 이름 오타('강남 점')와 날짜 형식('2026.03.05')을 통일한다
4. 중복 행과 빈 행을 제거한다
5. 지점별·월별 매출 합계표를 `결과/요약.xlsx`로 저장한다
6. 스크립트를 다시 실행해서 같은 결과가 나오는지 확인한다

## 🔥 도전 미션 (기본을 끝냈다면)
- 상품별 매출 TOP 3를 지점마다 뽑아 시트를 따로 만들기
- 요약 엑셀에 막대 차트 넣기
- `data` 폴더에 7월 파일을 새로 넣어도 자동으로 포함되게 만들기

```
```
