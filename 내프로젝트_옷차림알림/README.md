# 👕 내일 옷차림 알림봇

**매일 저녁 8시**, 기상청 예보로 **내일 광주의 시간별 기온**을 읽고, 그 기온에 맞는 **옷차림 후보**와 **우산 알림**을 내 지메일로 보내 주는 봇이에요.
옷은 내가 고르고, 봇은 고를 재료만 모아 줘요.

---

## 1. 무엇을 하나요?

```
기상청 단기예보 ──▶ 1_내일기온.py ──▶ 2_옷차림.py ──▶ 3_메일보내기.py ──▶ 📧 내 메일함
 (공공데이터포털)     '신문 배달원'      '코디 도우미'      '우체부'
                     내일 기온 받기     옷차림표 붙이기     지메일로 보내기
```

| 파일 | 하는 일 | 혼자 실행하면 |
|---|---|---|
| `1_내일기온.py` | 지금 받을 수 있는 **가장 최근 발표분**을 골라 내일 시간별 기온·강수확률을 받아요 | 아침/낮 최고/저녁 기온을 화면에 보여 줌 |
| `2_옷차림.py` | 00~23시 기온 전부 + **하루 최저~최고 기온이 걸친 옷차림 칸 모두** + 강수확률 60% 이상이면 ☔ | 메일 제목·본문을 화면에 미리 보여 줌 (메일은 안 보냄) |
| `3_메일보내기.py` | 2번이 만든 알림을 지메일로 보내고, 시각과 결과를 한 줄 남겨요 | **진짜 메일을 보냄** |

뒤 파일이 앞 파일을 불러 쓰기 때문에, **자동 실행은 `3_메일보내기.py` 하나만** 돌리면 1→2→3이 차례로 이어져요.

## 2. 설치

### ① 파이썬 확인 — 따로 설치할 도구 없음

맥 기본 `python3`의 표준 기능(`urllib`, `smtplib` 등)만 써요.

```bash
python3 --version
```

`Python 3.x`가 나오면 준비 끝이에요.

### ② 기상청 서비스키 받기 (처음 한 번)

1. [공공데이터포털](https://www.data.go.kr)에 로그인
2. **'기상청_단기예보 조회서비스'** 검색 → **활용신청** (약관 동의 체크는 직접)
3. 마이페이지 → 개발계정에서 **일반 인증키** 복사

### ③ 지메일 앱 비밀번호 만들기 (처음 한 번)

1. 구글 계정 → 보안 → **2단계 인증** 켜기
2. 구글 계정 검색창에 **'앱 비밀번호'** → 새로 만들기 → 16글자 복사
3. ⚠️ 앱 비밀번호를 만든 계정과 **보내는 메일 주소가 같아야** 해요 (다르면 535 로그인 실패)

### ④ 금고(`.env`) 만들기

이 폴더에 `.env` 파일을 만들고 아래 4줄을 채워요. **`.gitignore`로 GitHub에 안 올라가요.**

```
DATA_GO_KR_KEY=기상청_일반_인증키
GMAIL_ADDRESS=보내는주소@gmail.com
GMAIL_APP_PASSWORD=앱비밀번호16글자
MAIL_TO=받는주소@gmail.com
```

- `MAIL_TO`를 비우면 보내는 주소로(나에게) 보내요.
- 비밀이 화면에 보이지 않게 넣으려면, 값을 **먼저 복사한 뒤** 아래처럼 붙여 넣어요 (`>>`는 맨 아래에 덧붙이기, `>` 하나는 덮어쓰기라 조심):
  ```bash
  printf 'DATA_GO_KR_KEY=%s\n' "$(pbpaste)" >> .env
  ```

## 3. 사용법

**터미널에서 이 폴더로 먼저 들어가요.**

```bash
cd 내프로젝트_옷차림알림
```

| 하고 싶은 것 | 명령 |
|---|---|
| 내일 기온만 빨리 보기 | `python3 1_내일기온.py` |
| 메일 내용 미리 보기 (안 보냄) | `python3 2_옷차림.py` |
| 지금 바로 메일 보내기 | `python3 3_메일보내기.py` |

### 매일 20:00 자동 실행 켜기 (맥 launchd)

**①** 이 폴더에 `com.practicekit.outfit.plist` 파일을 만들어요. `내이름`과 폴더 경로는 **내 컴퓨터에 맞게** 바꿔요 (터미널에서 `pwd`로 확인).

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.practicekit.outfit</string>
    <key>ProgramArguments</key>
    <array>
        <string>/usr/bin/python3</string>
        <string>/Users/내이름/.../내프로젝트_옷차림알림/3_메일보내기.py</string>
    </array>
    <key>EnvironmentVariables</key>
    <dict>
        <key>PYTHONIOENCODING</key>
        <string>utf-8</string>
    </dict>
    <key>StartCalendarInterval</key>
    <dict>
        <key>Hour</key>
        <integer>20</integer>
        <key>Minute</key>
        <integer>0</integer>
    </dict>
    <key>StandardOutPath</key>
    <string>/Users/내이름/.../내프로젝트_옷차림알림/실행기록.log</string>
    <key>StandardErrorPath</key>
    <string>/Users/내이름/.../내프로젝트_옷차림알림/실행기록.log</string>
</dict>
</plist>
```

**②** 맥의 예약 서랍에 넣고 맡기기:

```bash
cp com.practicekit.outfit.plist ~/Library/LaunchAgents/
```

```bash
launchctl load ~/Library/LaunchAgents/com.practicekit.outfit.plist
```

**③** 잘 맡겨졌는지 확인 — `com.practicekit.outfit` 줄이 보이면 성공:

```bash
launchctl list | grep outfit
```

> 💡 **바로 확인하고 싶으면** 예약 시각을 몇 분 뒤로 바꿔서 맡겨 보고, 메일이 오면 다시 20:00으로 되돌려요.
> 예약을 바꿀 땐 **돌려받기 → 갈아 끼우기 → 다시 맡기기** (`unload` → `cp` → `load`).

### 자동 실행 끄기

```bash
launchctl unload ~/Library/LaunchAgents/com.practicekit.outfit.plist
```

```bash
rm ~/Library/LaunchAgents/com.practicekit.outfit.plist
```

## 4. 결과 예시

`python3 2_옷차림.py` (2026-11-22 11시 발표 기준, 내일 11/23 광주):

```
제목: [옷차림] 내일 11/23 광주 1~15℃ ☔
----------------------------------------
📅 내일 11/23 광주 (11/22 11시 발표 기준)
🌡️ 하루 기온: 1~15℃

⏰ 시간별 기온 (강수확률)
   00시    ○℃  💧○○%
   ...            (00~23시, 24줄)

👕 옷차림 (1~15℃ 범위에 드는 칸 모두)
   · 4℃ 이하: 패딩, 두꺼운 코트, 목도리, 기모제품
   · 5~8℃: 코트, 가죽자켓, 히트텍, 니트, 레깅스
   · 9~11℃: 자켓, 트렌치코트, 야상, 니트, 청바지, 스타킹
   · 12~16℃: 자켓, 가디건, 야상, 스타킹, 청바지, 면바지

☔ 우산 챙기세요 (최고 강수확률 60%, 17시)
```

`3_메일보내기.py`가 남기는 기록 (`실행기록.log`):

```
[2026-11-22 13:55] 📧 보냈어요: '[옷차림] 내일 11/23 광주 1~15℃ ☔' (36줄)
```

> 시간별 기온 줄의 숫자(○)는 그날 예보에 따라 매번 달라요. 하루 기온·옷차림 4칸·☔·36줄은 2026-11-22에 실제로 받은 결과예요.

## 5. 주의사항

| 상황 | 이렇게 돼요 / 이렇게 하세요 |
|---|---|
| `.env` 파일이 **아예 없음** | ❌ 영어 오류 `FileNotFoundError: ... .env`가 나와요 → 2-④대로 금고부터 만들어요 (새 컴퓨터에 `git clone`했을 때 가장 먼저 만나는 오류) |
| `.env`는 있는데 값이 비어 있음 | ⚠️ `DATA_GO_KR_KEY 값이 비어 있어요` 또는 `.env 금고를 확인해 주세요`가 나와요 |
| 기상청 `403` / 키 오류 | 키를 복사할 때 다른 글자가 들어갔는지 확인 (`pbpaste`는 **복사를 먼저** 해야 해요) |
| `현재 이후의 base_time은 호출할 수 없습니다` | 아직 안 나온 발표를 부른 것. 이 봇은 **발표 10분 뒤**부터 쓸 수 있는 발표를 스스로 골라서 보통 안 나와요 |
| 메일 `535` 로그인 실패 | 앱 비밀번호를 만든 계정 ≠ `GMAIL_ADDRESS`. 같은 계정으로 맞춰요 |
| 지역 바꾸기 | `1_내일기온.py`의 `NX, NY = 58, 74`(광주 격자)를 바꿔요. 격자 좌표는 기상청 활용가이드 엑셀에 있어요 |
| 옷차림·우산 기준 바꾸기 | `2_옷차림.py`의 `CLOTHES` 표, `UMBRELLA_POP = 60` |
| 맥이 잠자기 중 | 20:00에 자고 있었다면 **깨어날 때 한 번** 대신 실행돼요. 꼭 제시간에 받으려면 잠자기를 꺼 두세요 |
| 자동 실행 때 한글 깨짐 | 예약표의 `PYTHONIOENCODING=utf-8` 줄을 지우지 마세요 |
| GitHub에 올리면 안 되는 것 | `.env`(키·비밀번호), `*.plist`·`*.log`(내 컴퓨터 경로·사용자 이름) — 모두 `.gitignore`에 들어 있어요 |
