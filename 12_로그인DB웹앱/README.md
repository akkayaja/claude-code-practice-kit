# 12. 로그인과 DB가 있는 웹앱

> **얻는 능력:** 회원가입·저장·조회·수정·삭제가 되는 '진짜 서비스'를 만드는 능력

**왜 배우나요?** 웹서비스 대부분은 '로그인 + 데이터 저장/조회'의 조합이에요. 이 뼈대를 한 번 만들어 보면 서비스가 어떻게 돌아가는지 감이 옵니다.

## 📁 들어 있는 파일
- `seed/books.json` – 사내 도서 대여 관리 앱에 넣을 초기 책 10권 데이터
- `요구사항.md` – 만들 앱의 기능 명세

## 🧭 기본 미션 (순서대로)
1. `요구사항.md`를 읽고 화면 목록을 정리한다
2. 먼저 로그인 없이 책 목록 보기·추가·삭제가 되는 버전을 만든다 (내 컴퓨터에서만)
3. Supabase 무료 계정을 만들고 DB에 책 데이터를 넣는다
4. 로그인 기능을 붙인다
5. 대여/반납 기능을 붙인다

## 🔥 도전 미션 (기본을 끝냈다면)
- 관리자만 책을 추가할 수 있게 권한 나누기
- 11번처럼 배포해서 링크로 공유하기
- 대여 기록 대시보드 만들기
