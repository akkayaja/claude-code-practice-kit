# 포트폴리오 한 줄 모음

학습일지에서 자동으로 모았어요. (`1_한줄모으기.py`)

## 01_엑셀자동화

- **문제:** 매달 지점별 엑셀 6개를 손으로 합치고, 오타·날짜 형식·중복을 하나하나 고쳐야 했다
- **해결:** 파이썬(pandas) 스크립트로 취합 → 정리 → 지점별·월별 합계 → TOP 3 → 차트까지 한 번에 처리하고, 합계 검증까지 자동화
- **효과:** 수작업 취합 → 명령어 한 줄로 몇 초 만에 완료, 새 달 파일은 `data` 폴더에 넣기만 하면 자동 포함

## 02_보고서자동생성

- **문제:** 각 팀이 보낸 실적 엑셀 5개를 손으로 열어 세고, 표로 정리하고, 이슈를 골라 보고서 양식에 옮겨 적어야 했다
- **해결:** 파이썬(pandas) 스크립트로 취합 → 달성률·팀별 표·이슈 목록 계산 → 양식 자동 채우기 → Word 저장까지 한 번에 처리하고, 주차 선택과 지연 팀 자동 강조 기능을 추가
- **효과:** 수작업 취합·작성 → 명령어 한 줄로 몇 초 만에 .md와 Word 보고서 완성, 주차별 보고서도 `3주차`만 붙이면 바로 생성

## 03_메일분류

- **문제:** 매일 쏟아지는 업무 메일을 하나씩 열어 읽고, 견적·청구서·고객문의·공지·스팸으로 나누고, 첨부파일을 따로 저장하고, 청구 금액을 더하고, 고객 답장을 써야 했다
- **해결:** 파이썬으로 메일 파일을 읽어 키워드 규칙대로 폴더 분류 → 첨부 저장 → 청구서 금액 합계 → 고객문의 답장 초안까지 자동화하고, 같은 분류를 Claude API에도 맡겨 정답과 비교 채점
- **효과:** 메일 20통 분류·첨부 정리·금액 합계·답장 초안을 명령어 몇 줄로 몇 초 만에 완료, 정확도 90% → 규칙 수정 후 100%, AI 분류도 힌트 없이 100%

## 04_구글시트폼자동화

- **문제:** 구글폼 특강 신청 60건을 손으로 세고, 미동의자·중복·정원 초과·문의사항을 일일이 확인하고, 신청자마다 확인 메일을 따로 보내야 했다
- **해결:** 파이썬으로 집계·검증 기준을 먼저 만든 뒤, Apps Script + 트리거로 과목별 요약 · 정원 초과 '대기' 표시 · 문의 행 강조 · 확인 메일 발송을 한 번에 자동화
- **효과:** 신청이 들어오면 사람이 손대지 않아도 몇 초 안에 요약표 갱신 + 상태 표시 + 확인 메일까지 끝 (수작업 약 1시간 → 자동)

## 05_PDF정보추출

- **문제:** 거래명세서 PDF를 한 장씩 열어 문서번호·날짜·공급자·금액을 엑셀에 손으로 옮겨 적어야 했고, 옮겨 적다 틀려도 알아채기 어려웠다
- **해결:** 파이썬(pdfplumber)으로 PDF 8장에서 필요한 값과 품목 표를 자동으로 뽑아 엑셀에 저장하고, 공급가액 + 부가세 = 합계·부가세 10%·품목 합 검증과 공급자별 집계까지 자동화
- **효과:** 수작업 입력 → 명령어 한 줄로 몇 초 만에 완료, 정답과 56칸 100% 일치, 금액 오류가 있으면 ❌로 바로 표시

## 06_데이터분석리포트

- **문제:** 지역·분기별 카페 데이터와 실제 공공데이터를 보고 "어디가 위험하고, 어디가 성장하는지"를 판단하려면 엑셀로 일일이 계산하고 그래프를 그려야 했고, 데이터의 구멍이나 이상한 값을 놓치기 쉬웠다
- **해결:** 파이썬(pandas, matplotlib)으로 데이터 점검 → 질문별 표·그래프 → 한 줄 결론 → HTML 리포트까지 자동으로 만들고, 실제 공공데이터에서는 빠진 달·튀는 값을 찾아 믿을 수 있는 구간만 골라 분석과 예측을 했다
- **효과:** 질문 3개짜리 분석 리포트를 명령어 몇 줄로 몇 초 만에 다시 만들 수 있고, 리포트 파일 하나로 그래프·결론·주의할 점까지 공유 가능

## 07_SQL연습

- **문제:** 고객·상품·주문이 따로 저장된 쇼핑몰 데이터에서 매출 추이, 우수 고객, 반품이 많은 상품, 지역별 인기 상품을 알아내려면 여러 표를 일일이 대조해야 했다
- **해결:** SQL로 표를 JOIN해 15가지 질문에 답하고, 파이썬으로 같은 SQL을 실행해 그래프와 결론이 담긴 HTML 리포트를 자동으로 만들었다. 총액만 보지 않고 1인당으로 다시 계산해 "VIP 등급이 실제 구매력을 반영하지 못한다"는 점을 찾아냈다
- **효과:** 표 3개 · 주문 1,500건 분석을 SQL 몇 줄로 몇 초 만에 끝내고, 데이터가 바뀌어도 명령어 한 줄로 리포트를 다시 만들 수 있다

## 08_대시보드

- **문제:** 4개 판매채널의 1년치 일별 매출(1,460줄)을 보고서로 읽어야 해서, 채널별 성과·월별 흐름·요일 패턴을 한눈에 파악하기 어려웠다
- **해결:** 파이썬으로 KPI 카드 · 월별 추이 · 채널 비중 · 전월 대비 증감률 · 요일 히트맵을 담은 HTML 대시보드를 만들고, 채널 필터와 "CSV만 바꾸면 자동 갱신"까지 구현했다
- **효과:** 엑셀로 매번 집계하고 차트를 그리던 작업을 명령어 한 줄로 끝내고, 연말 매출 급증(11월 +21.6%)·주말 매출 강세(토요일 +15%) 같은 의사결정 포인트를 바로 볼 수 있게 됐다

## 09_웹크롤링

- **문제:** 쇼핑몰 상품 45개의 가격·평점·판매자·재고를 확인하려면 목록 3페이지와 상세 페이지 45개를 하나씩 눌러 옮겨 적어야 했고, 가격이 바뀌어도 알 방법이 없었다
- **해결:** 파이썬(requests·BeautifulSoup)으로 목록과 상세 페이지를 자동으로 돌며 수집해 CSV로 저장하는 크롤러와, 지난번 가격과 비교해 바뀐 상품을 알려 주는 모니터링을 만들었다
- **효과:** 손으로 하면 1시간 넘게 걸릴 수집을 1분 안에 끝냈고, 재고가 거의 바닥난 상품(2개 남음)과 가격 변동(−12.5%, +16.7%)을 자동으로 찾아냈다

## 10_Git기초

- **문제:** 작업 기록이 없어 실수하면 되돌릴 수 없고, 한 일을 남에게 보여 줄 방법이 없었다
- **해결:** Git으로 세이브·되돌리기·브랜치 실험을 익히고, GitHub에 실습 저장소를 만들어 기록을 쌓기 시작
- **효과:** 실수해도 몇 초 만에 복구, 실습할 때마다 "오늘 기록 남겨 줘" 한마디로 학습일지 작성부터 GitHub 업로드까지 자동으로

## 11_웹페이지배포

- **문제:** 가게 소개 웹페이지를 만들려면 외주를 맡기거나 코딩을 오래 배워야 했다
- **해결:** Claude Code에게 구성안을 받아 HTML 한 파일로 반응형 랜딩페이지(다크모드·문의 폼 포함)를 만들고, GitHub에 올린 뒤 Vercel로 배포
- **효과:** 외주 없이 하루 만에 휴대폰에서도 잘 보이는 사이트를 인터넷 주소로 공개 (https://onggi-cafe-practice.vercel.app)

## 12_로그인DB웹앱

- **문제:** 사내 도서 대여를 엑셀·종이 장부로 관리하면 누가 언제 빌렸는지, 연체가 있는지 확인하기 어렵다
- **해결:** Supabase(데이터베이스·로그인·행 단위 보안)와 HTML·JavaScript로 회원가입, 검색, 대여·반납(1인 3권·14일·연체 표시), 관리자 권한, 대여 기록 대시보드를 갖춘 웹앱을 만들고 Vercel로 배포
- **효과:** 서버 개발 없이 하루 만에 로그인과 DB가 있는 서비스를 링크 하나로 공유 (https://book-rental-practice.vercel.app)

## 13_API연결

- **문제:** 여러 도시의 날씨를 확인하려면 사이트를 하나씩 찾아보고 손으로 옮겨 적어야 했다
- **해결:** 파이썬으로 기상청 공공 API에 연결해 7개 도시의 현재 기온·습도·강수를 한 번에 받아 표로 정리하고, 결과를 CSV에 중복 없이 쌓도록 자동화. 인증키는 `.env`로 분리하고 서버 오류·없는 도시도 멈추지 않게 처리
- **효과:** 7개 도시 날씨 확인·기록 수작업 약 10분 → 명령어 한 줄로 몇 초, 매일 실행하면 날씨 데이터가 저절로 쌓임

## 14_자동실행봇

- **문제:** 매일 아침 할 일 목록을 열어 마감이 지난 일·오늘 할 일을 직접 골라내고, 날씨도 따로 찾아봐야 했다
- **해결:** 파이썬으로 할 일을 마감 기준·중요도 순으로 정리한 '오늘의 브리핑'을 만들고, 13번의 기상청 API 날씨를 붙여 지메일로 보내도록 조립. 맥 launchd로 매일 정해진 시각에 사람 없이 실행되게 예약하고, 실행 기록과 해제 방법까지 정리
- **효과:** 아침 정리 수작업 약 10분 → 0분 (정해진 시각에 메일함에 브리핑 도착), 날씨 데이터도 매일 저절로 쌓임

## 15_프롬프트템플릿

- **문제:** AI에게 그때그때 "답글 써 줘"라고 시키면 답글이 1~5개, 457~912자로 매번 달라지고, 빈칸·가짜 연락처·함부로 한 보상 약속이 섞여 그대로 쓸 수 없었다
- **해결:** 역할·판단 기준·금지사항·출력형식을 정한 프롬프트 템플릿을 만들고 결과를 보며 3번 개선(v1→v4), Claude API 스크립트로 리뷰 15개에 감정·답글·담당팀·긴급도를 한 번에 붙여 CSV로 저장
- **효과:** 리뷰 15개 처리가 명령 한 줄로 끝나고, 여러 번 돌려도 같은 분류가 나오며, 오늘 연락해야 할 리뷰 5건이 바로 보인다. 같은 틀로 회의록 요약·이메일 답장 템플릿까지 확장

## 16_문서기반AI챗봇

- **문제:** 직원들이 휴가·출장비·보안·복지·재택 규정을 물을 때마다 담당자가 문서를 찾아 답해야 하고, 그냥 AI에 물으면 우리 회사 규정을 모르니 그럴듯하게 지어낼 위험이 있었다
- **해결:** 규정 문서를 조각 22개로 나눠 검색하고, 찾은 조각만 근거로 Claude가 답하는 RAG 챗봇을 만들었다. 문서에 없으면 "없다"고 답하게 하고, 답마다 근거 문서를 표시하며, 테스트 질문 9개 자동 채점과 웹 채팅 화면까지 붙였다
- **효과:** 테스트 9문항 모두 정답(문서에 없는 '주차비' 질문은 지어내지 않고 "문서에 없다"), 근거 문서 9개 모두 일치. 규정 질문에 몇 초 만에 근거와 함께 답한다

## 17_AI에이전트워크플로우

- **문제:** 글 하나를 쓰려면 기획·초안·검수·수정을 사람이 차례로 하고, 검수 기준(제목 길이·분량·근거 없는 숫자 등)을 눈으로 하나하나 확인해야 했다
- **해결:** 기획자·작가·편집장 AI 에이전트로 단계를 나누고 자동으로 이었다. 검수 불통과면 최대 2번 고쳐 다시 검수하고, 글자 수는 코드가 판정하며, 발행 전 사람 승인·반려 단계와 단계별 시간·비용 기록, Claude Code 서브에이전트 버전까지 만들었다
- **효과:** 주제 5개를 약 1분, 글 1편당 약 130원에 처리하고 5편 모두 검수 6개 항목 통과. 수정·검수 기록이 CSV로 남아 어디서 자주 걸리는지 숫자로 확인할 수 있다

## 18_스킬과MCP만들기

- **문제:** 주간보고·리뷰 응대처럼 반복되는 일을 매번 명령어와 규칙을 기억해 처리해야 했고, AI는 회사 DB를 볼 수 없었으며, 연결하더라도 데이터를 망가뜨릴 위험이 있었다
- **해결:** 업무 순서·양식·기준을 Claude Code 스킬 2개로 만들고, 매출·고객 DB 조회를 MCP 서버(읽기 전용 자물쇠 3겹)로 연결한 뒤, 플러그인으로 포장해 동료가 한 줄로 설치하게 함
- **효과:** "주간보고 써 줘", "지난달 매출 알려 줘", "이 리뷰 답글 달아 줘" 한마디로 처리 (명령어·기준 암기 불필요), DB 수정 시도 5/5 차단

## 19_문서화연습

- **문제:** 이름이 `f`, `g`, `a`뿐이고 설명도 없는 스크립트라, 무슨 일을 하는지·어떻게 쓰는지 아무도 알 수 없었다 (값을 틀리게 넣으면 `?`만 출력)
- **해결:** 코드를 읽어 동작을 밝혀내고, 이름·주석·오류 안내를 정리한 뒤(결과는 `cmp`로 원본과 동일 확인) README를 작성. 내가 만든 자동화 봇 3개에도 설명서를 붙이고, 설명서만 받은 초보자 시험으로 빠진 설명을 보충
- **효과:** 처음 보는 사람도 README의 명령만 따라 해서 같은 결과(월별 매출 12줄, 1년 25.4억 원)를 얻을 수 있게 됨 — 6개월 뒤의 나, 동료, 고객에게 넘겨줄 수 있는 도구가 됨

## 내프로젝트_옷차림알림

- **문제:** 매일 밤 내일 날씨 앱을 열어 시간별 기온을 보고 옷을 고민해야 했다
- **해결:** 기상청 공공 API + 기온별 옷차림표 + 지메일 + 맥 launchd로, 매일 20:00에 내일 시간별 기온·옷차림 후보·우산 알림을 메일로 보내는 봇을 만들어 상시 켜진 맥미니에서 운영
- **효과:** 아무것도 누르지 않아도 매일 저녁 메일 한 통으로 내일 옷차림 준비 끝
