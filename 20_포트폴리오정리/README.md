# 20. 포트폴리오로 정리하기

> **얻는 능력:** '무엇을 문제로 보고, 어떻게 해결했고, 얼마나 효과가 있었는지'를 보여주는 능력

**왜 배우나요?** 지금까지 만든 19개가 곧 경력이에요. 기술 나열보다 '문제 → 해결 → 효과' 이야기로 정리하면 면접·외주 모두에서 강력합니다.

## 📁 들어 있는 파일
- `사례정리_양식.md` – 프로젝트 하나를 정리하는 양식
- `포트폴리오_체크리스트.md` – 완성도 점검표

## 🧭 기본 미션 (순서대로)
1. 각 폴더 README 맨 아래 '포트폴리오 한 줄'을 모은다
2. 가장 자신 있는 3개를 골라 `사례정리_양식.md`로 자세히 쓴다
3. 스크린샷이나 결과 이미지를 넣는다
4. 11번처럼 포트폴리오 웹사이트를 만들어 배포한다
5. GitHub 프로필에 링크를 연결한다

## 🔥 도전 미션 (기본을 끝냈다면)
- 실제 업무에서 비슷한 문제를 찾아 개선 제안서로 만들기
- '비전공 직장인이 AI로 업무자동화 20개 만들어 본 기록'으로 블로그 연재

