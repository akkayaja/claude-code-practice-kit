# 07. SQL로 데이터에 질문하기

> **얻는 능력:** 데이터베이스에서 원하는 데이터를 직접 꺼내는 능력 (채용공고 단골 요구사항)

**왜 배우나요?** 데이터 분석·기획·마케팅·운영 직무 채용공고에 'SQL 가능자 우대'가 정말 많아요. 엑셀로 안 되는 규모의 데이터를 다루는 첫걸음입니다.

## 📁 들어 있는 파일
- `shop.db` – 가상 쇼핑몰 DB (SQLite). 고객 200명, 상품 12개, 주문 1,500건
- `문제.md` – 단계별 SQL 문제 15개

## 🧭 기본 미션 (순서대로)
1. Claude Code에 DB의 테이블 구조를 설명해 달라고 한다
2. `문제.md`의 1~5번(기초)을 **먼저 직접 써 보고**, 막히면 힌트만 요청한다
3. 6~10번(집계·JOIN)을 푼다
4. 11~15번(실전 분석)을 푼다
5. 자주 쓴 SQL 문법을 `내_SQL_노트.md`에 정리한다

## 🔥 도전 미션 (기본을 끝냈다면)
- DB Browser for SQLite 같은 무료 프로그램으로 DB를 열어 보기
- 분석 결과를 06번처럼 그래프 리포트로 만들기

## 💬 Claude Code에 이렇게 말해 보세요
막히면 아래 문장을 그대로 복사해서 써도 돼요. 단, **먼저 결과를 직접 실행해 보고, 코드에서 모르는 줄은 "이 줄이 뭐 하는 거야?"라고 꼭 물어보세요.** 그래야 실력이 남아요.

```
shop.db 의 테이블 구조와 각 열의 의미를 설명해 줘.
```
```
문제.md 3번을 내가 이렇게 풀었는데 맞는지 실행해 보고, 틀렸으면 정답 대신 힌트만 줘: SELECT ...
```
```
JOIN이 뭔지 이 DB 예시로 쉽게 설명해 줘.
```
