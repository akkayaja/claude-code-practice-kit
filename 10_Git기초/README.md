# 10. Git과 GitHub 사용 습관

> **얻는 능력:** 작업 기록을 남기고, 되돌리고, 공유하는 능력

**왜 배우나요?** Git은 '저장 기록 + 되돌리기 + 온라인 백업'이에요. 포트폴리오를 GitHub에 올려 두면 그 자체가 이력서가 됩니다.

## 📁 들어 있는 파일
- `my_first_repo/` – 연습용 작은 폴더 (메모.md, 할일.txt)

## 🧭 기본 미션 (순서대로)
1. `my_first_repo` 폴더에서 Git 저장소를 시작한다 (git init)
2. 파일을 수정하고 첫 커밋을 한다
3. 파일을 망가뜨린 뒤 이전 커밋으로 되돌려 본다
4. 브랜치를 만들어 실험하고, 다시 합친다 (merge)
5. GitHub 계정을 만들고 저장소를 올린다 (push)
6. 앞으로 01~09번 실습 폴더도 GitHub에 올린다

## 🔥 도전 미션 (기본을 끝냈다면)
- README를 예쁘게 꾸며 GitHub 프로필에 고정하기
- 일부러 충돌(conflict)을 만들고 해결해 보기
- .gitignore로 올리면 안 되는 파일 제외하기

## 💬 Claude Code에 이렇게 말해 보세요
막히면 아래 문장을 그대로 복사해서 써도 돼요. 단, **먼저 결과를 직접 실행해 보고, 코드에서 모르는 줄은 "이 줄이 뭐 하는 거야?"라고 꼭 물어보세요.** 그래야 실력이 남아요.

```
Git이 뭔지 비유로 설명해 줘. 그리고 my_first_repo 폴더를 Git 저장소로 만들고 첫 커밋을 같이 해 줘. 명령어마다 무슨 뜻인지 알려 줘.
```
```
할일.txt를 실수로 지웠다고 치고 되돌리는 법을 알려 줘.
```
```
GitHub에 올리는 법을 단계별로 알려 줘. 계정 만들기와 로그인은 내가 직접 할게.
```
