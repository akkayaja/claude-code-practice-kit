# 08. 한눈에 보는 대시보드 만들기

> **얻는 능력:** 숫자를 보고 바로 의사결정할 수 있게 시각화하는 능력

**왜 배우나요?** 보고서는 읽어야 하지만 대시보드는 '보면' 됩니다. 경영진이 좋아하는 형태라 실무에서 활용도가 높아요.

## 📁 들어 있는 파일
- `data/일별_채널별_매출_2025.csv` – 2025년 1년치, 4개 판매채널의 일별 주문수·매출액·방문자수

## 🧭 기본 미션 (순서대로)
1. 대시보드에 넣을 핵심 숫자 3~4개(KPI)를 먼저 정한다 (예: 총매출, 주문수, 객단가, 전환율)
2. 월별 매출 추이 그래프를 만든다
3. 채널별 매출 비중 그래프를 만든다
4. 모든 것을 HTML 파일 하나로 만들어 브라우저에서 연다
5. 채널을 선택하면 숫자가 바뀌는 필터를 넣는다

## 🔥 도전 미션 (기본을 끝냈다면)
- 전년 대비·전월 대비 증감률 표시
- 요일별 매출 패턴 히트맵
- CSV 파일만 교체하면 대시보드가 자동 갱신되게 만들기

## 💬 Claude Code에 이렇게 말해 보세요
막히면 아래 문장을 그대로 복사해서 써도 돼요. 단, **먼저 결과를 직접 실행해 보고, 코드에서 모르는 줄은 "이 줄이 뭐 하는 거야?"라고 꼭 물어보세요.** 그래야 실력이 남아요.

```
data 폴더의 매출 CSV로 HTML 대시보드를 만들어 줘. 상단에 총매출·주문수·객단가·전환율 카드, 아래에 월별 추이와 채널별 비중 차트, 그리고 채널 필터를 넣어 줘. 파일 하나로 열리게 해 줘.
```
