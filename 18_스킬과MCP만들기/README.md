# 18. Claude Code 스킬과 MCP 만들기

> **얻는 능력:** AI 도구를 내 업무에 맞게 커스터마이징하는 능력

**왜 배우나요?** 스킬은 'AI에게 주는 업무 매뉴얼', MCP는 'AI에게 달아 주는 새 손'이에요. 반복 업무를 스킬로 만들고, 회사 데이터를 MCP로 연결할 줄 알면 AI 도입 담당자가 될 수 있습니다.

## 📁 들어 있는 파일
- `(없음)` – 앞에서 만든 실습 결과물을 재활용합니다: 02번(주간보고), 07번(shop.db)

## 🧭 기본 미션 (순서대로)
1. **스킬:** 02번 주간보고 작업을 '주간보고-작성' 스킬로 만든다 (양식·규칙·순서를 담은 SKILL.md)
2. 새 대화에서 '주간보고 써 줘'라고 했을 때 스킬이 쓰이는지 확인한다
3. **MCP:** 07번 shop.db 를 조회하는 아주 작은 MCP 서버를 만든다 (도구 2개: 매출 조회, 고객 검색)
4. Claude Code에 MCP를 연결하고 '지난달 매출 알려 줘'라고 물어본다
5. 만든 스킬과 MCP 사용법을 README로 정리한다

막히면 아래 문장을 그대로 복사해서 써도 돼요. 단, **먼저 결과를 직접 실행해 보고, 코드에서 모르는 줄은 "이 줄이 뭐 하는 거야?"라고 꼭 물어보세요.** 그래야 실력이 남아요.

```

```
```
MCP가 뭔지 비유로 설명해 줘. 그리고 07_SQL연습/shop.db 를 읽기 전용으로 조회하는 간단한 MCP 서버를 만들고 Claude Code에 연결하는 방법을 알려 줘.
```
