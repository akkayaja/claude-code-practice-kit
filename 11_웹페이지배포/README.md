# 11. 웹페이지 만들어 배포하기

> **얻는 능력:** 결과물을 인터넷 주소로 세상에 보여주는 능력

**왜 배우나요?** 만든 걸 링크 하나로 보여줄 수 있으면 면접·외주·포트폴리오 모두에서 설득력이 확 올라가요.

## 📁 들어 있는 파일
- `content/카페정보.md` – 가상의 카페 '오늘의 온기' 소개 자료 (메뉴·영업시간·위치)

## 🧭 기본 미션 (순서대로)
1. 자료를 읽고 페이지 구성을 정한다 (첫 화면 / 메뉴 / 영업시간·위치 / 연락처)
2. HTML 파일 하나로 랜딩페이지를 만든다
3. 휴대폰 화면에서도 깨지지 않는지 확인한다
4. 10번에서 배운 대로 GitHub에 올린다
5. Vercel(또는 GitHub Pages)로 배포해서 주소를 받는다

## 🔥 도전 미션 (기본을 끝냈다면)
- 내 포트폴리오 사이트를 같은 방식으로 만들기 (20번과 연결)
- 다크모드 추가
- 문의 폼 넣기

## 💬 Claude Code에 이렇게 말해 보세요
막히면 아래 문장을 그대로 복사해서 써도 돼요. 단, **먼저 결과를 직접 실행해 보고, 코드에서 모르는 줄은 "이 줄이 뭐 하는 거야?"라고 꼭 물어보세요.** 그래야 실력이 남아요.

```
content/카페정보.md 로 카페 랜딩페이지를 만들어 줘. HTML 파일 하나로, 모바일에서도 예쁘게. 섹션 구성은 먼저 나한테 제안해 줘.
```
```
이 페이지를 GitHub에 올리고 Vercel로 배포하는 방법을 단계별로 알려 줘. 계정 가입은 내가 할게.
```
