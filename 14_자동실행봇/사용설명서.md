# 📋 아침 브리핑 봇 — 사용설명서

> 이 폴더의 `README.md`는 14번 **실습 안내서**예요. 만든 봇을 **쓰는 법**은 이 파일에 있어요.

매일 아침 **할 일 목록**을 마감 기준으로 나누고, **기상청 실황 날씨(7개 도시)**를 맨 위에 붙여 '오늘의 브리핑' 파일을 만들어요.
금고(`.env`)가 있으면 완성된 브리핑을 **내 지메일로** 보내 주고, 맥의 예약(launchd)으로 **매일 08:50 자동 실행**할 수 있어요.

---

## 1. 무엇을 하나요?

`3_날씨브리핑.py`가 **지휘자**예요. 다른 스크립트들에게 차례로 일을 시켜요.

```
3_날씨브리핑.py (지휘자)
  ├─ [1/4] 13_API연결/4_날씨기록.py   → 13_API연결/날씨기록.csv 에 7개 도시 날씨 한 줄씩 쌓기
  ├─ [2/4] 2_브리핑저장.py            → 브리핑/오늘의브리핑_날짜.txt 만들기
  ├─ [3/4] 가장 최근 관측 날씨를 브리핑 맨 위에 끼워 넣기
  └─ [4/4] 4_메일보내기.py            → 내 지메일로 보내기 (.env 금고가 있을 때만)
```

| 파일 | 하는 일 | 파일을 만드나? |
|---|---|---|
| `1_분류.py` | 할 일을 마감 지남 / 오늘 / 이번 주 / 그 뒤로 나눠 **화면에만** 보여 주기 | ❌ |
| `2_브리핑저장.py` | 같은 분류를 `브리핑/오늘의브리핑_날짜.txt`로 저장 | ✅ |
| `3_날씨브리핑.py` | 지휘자 (위 그림) | ✅ (+ 메일) |
| `4_메일보내기.py` | 오늘 브리핑 파일을 **나에게만** 메일로 보내기 | ❌ (메일) |
| `data/할일목록.csv` | 할 일 25개 (할일·마감일·중요도·상태) | — |

**분류 기준:** `상태`가 `완료`인 일은 빼고 세요. 이번 주 = **내일부터 7일 안**. 각 묶음 안에서는 **중요도 높은 순 → 마감 빠른 순**.

## 2. 설치

### ① 파이썬 — 따로 설치할 도구 없음

맥 기본 `python3`의 표준 기능만 써요.

```bash
python3 --version
```

### ② 날씨 키 — 13번 금고

날씨는 **13번 `4_날씨기록.py`**가 받아요. 그래서 기상청 키는 `13_API연결/.env`에 있어야 해요.

```
DATA_GO_KR_KEY=기상청_일반_인증키
```

키가 없어도 **할 일 브리핑은 그대로** 만들어져요 (날씨 칸만 "기록이 아직 없어요").

### ③ 메일 — 14번 금고 (선택)

메일로 받고 싶을 때만 `14_자동실행봇/.env`를 만들어요. **`.gitignore`로 GitHub에 안 올라가요.**

```
GMAIL_ADDRESS=내주소@gmail.com
GMAIL_APP_PASSWORD=앱비밀번호16글자
```

앱 비밀번호는 구글 계정 → 보안 → 2단계 인증 → **'앱 비밀번호'**에서 만들어요. 만든 계정과 `GMAIL_ADDRESS`가 **같아야** 해요.

## 3. 사용법

**터미널에서 이 폴더로 먼저 들어가요.**

```bash
cd 14_자동실행봇
```

| 하고 싶은 것 | 명령 |
|---|---|
| 오늘 할 일 화면으로 보기 | `python3 1_분류.py` |
| **다른 날이라고 가정**해 보기 (연습용) | `python3 1_분류.py 2026-11-25` |
| 브리핑 파일만 만들기 (날씨·메일 없이) | `python3 2_브리핑저장.py` |
| 날씨 + 브리핑 + 메일 한 번에 | `python3 3_날씨브리핑.py` |

> ⚠️ `.env`가 있으면 `3_날씨브리핑.py`는 **진짜 메일을 보내요.** 연습할 땐 `1_분류.py`나 `2_브리핑저장.py`를 쓰세요.

### 매일 08:50 자동 실행 켜기

예약표 원본 `com.practicekit.briefing.plist`가 이 폴더에 있어요 (내 컴퓨터 경로가 들어 있어 GitHub에는 안 올라가요).

```bash
cp com.practicekit.briefing.plist ~/Library/LaunchAgents/
```

```bash
launchctl load ~/Library/LaunchAgents/com.practicekit.briefing.plist
```

잘 맡겨졌는지 확인 — `com.practicekit.briefing` 줄이 보이면 켜진 거예요:

```bash
launchctl list | grep briefing
```

> 💡 **바로 확인하고 싶으면** 예약표의 `Hour`/`Minute`를 몇 분 뒤로 바꿔 맡겨 보고, `자동실행기록.log`에 줄이 생기는지 봐요.
> 시각을 바꿀 땐 **끄기 → 고치기 → 다시 켜기** 순서예요.

### 자동 실행 끄기

```bash
launchctl unload ~/Library/LaunchAgents/com.practicekit.briefing.plist
```

```bash
rm ~/Library/LaunchAgents/com.practicekit.briefing.plist
```

`launchctl list | grep briefing`에 **아무것도 안 나오면** 완전히 꺼진 거예요.

### 새 컴퓨터에서 예약표 만들기

`.plist` 파일은 GitHub에 없어요. 이 폴더에 아래 내용으로 만들고 `/Users/내이름/...` 부분을 내 경로로 바꿔요 (`pwd`로 확인).

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.practicekit.briefing</string>
    <key>ProgramArguments</key>
    <array>
        <string>/usr/bin/python3</string>
        <string>/Users/내이름/.../14_자동실행봇/3_날씨브리핑.py</string>
    </array>
    <key>StartCalendarInterval</key>
    <dict>
        <key>Hour</key>
        <integer>8</integer>
        <key>Minute</key>
        <integer>50</integer>
    </dict>
    <key>StandardOutPath</key>
    <string>/Users/내이름/.../14_자동실행봇/자동실행기록.log</string>
    <key>StandardErrorPath</key>
    <string>/Users/내이름/.../14_자동실행봇/자동실행기록.log</string>
</dict>
</plist>
```

## 4. 결과 예시

`브리핑/오늘의브리핑_2026-11-22.txt` (2026-11-22 13:00 실행):

```
📋 오늘의 브리핑 — 2026-11-22 (일)
만든 시각: 2026-11-22 13:00:02
========================================

🌤️ 오늘 아침 날씨 (기상청 실황, 2026-11-22 12:00 관측)
  - 서울: 3.2℃, 습도 40%, 강수 없음
  - 부산: 6℃, 습도 36%, 강수 없음
  ...                                   (7개 도시)

🔴 마감 지남: 7개
  - [높음] 주간보고 작성 (8일 지남, 대기)
  ...
🟠 오늘 마감: 2개
  - [낮음] 거래처 미팅 준비 (오늘, 대기)
  - [낮음] 교육 이수 (오늘, 대기)
```

|---|---:|---:|---:|---:|---:|
| 2026-11-22 | 7 | 2 | 6 | 5 | 5 |
| 2026-11-25 | 10 | 0 | 8 | 2 | 5 |

## 5. 주의사항

| 상황 | 이렇게 돼요 / 이렇게 하세요 |
|---|---|
| 같은 날 여러 번 실행 | 그날 브리핑 파일을 **덮어써요**. 날씨기록.csv는 같은 관측 시각·도시를 두 번 적지 않아요 |
| 날씨 받기 실패 (키 없음·인터넷 끊김) | `[1/4] 날씨 기록: 실패`가 나와도 **할 일 브리핑은 계속** 만들어요 |
| 메일 `535` 로그인 실패 | 앱 비밀번호를 만든 계정 ≠ `GMAIL_ADDRESS`. 같은 계정으로 맞춰요 |
| 메일이 안 감 | `.env`가 없으면 `[4/4] 메일: .env 금고가 없어서 건너뛰었어요` — 오류가 아니라 정상 |
| 받는 사람 | 보내는 사람 = 받는 사람 = **나**. 다른 사람에게는 보내지 않아요 |
| 맥이 잠자기 중 | 08:50에 자고 있었다면 **깨어날 때 한 번** 대신 실행돼요 |
| 자동 실행이 안 된 것 같음 | `자동실행기록.log`를 열어 봐요. 실행될 때마다 [1/4]~[4/4] 줄이 쌓여요 |
| 할 일 바꾸기 | `data/할일목록.csv`를 엑셀로 고쳐요. `중요도`는 `높음/보통/낮음`, `마감일`은 `2026-11-25` 모양 |
| GitHub에 올리면 안 되는 것 | `.env`, `*.plist`, `*.log` (비밀번호·내 컴퓨터 경로) — `.gitignore`에 들어 있어요 |
