# 14. 정해진 시간에 자동 실행되는 봇

> **얻는 능력:** 사람이 없어도 프로그램이 알아서 돌게 만드는 능력 (스케줄링)

**왜 배우나요?** '매일 아침 9시에 오늘 할 일 정리해서 보내기' 같은 걸 만들 수 있으면 자동화의 완성 단계예요.

## 📁 들어 있는 파일
- `data/할일목록.csv` – 할 일 25개 (마감일·중요도·상태)

## 🧭 기본 미션 (순서대로)
1. 오늘 기준으로 마감 지난 일 / 오늘 마감 / 이번 주 마감을 분류하는 스크립트를 만든다
2. 결과를 보기 좋은 '오늘의 브리핑' 텍스트 파일로 저장한다
3. 수동으로 몇 번 실행해 결과를 확인한다
4. 맥의 스케줄러(cron 또는 launchd)로 매일 아침 자동 실행되게 설정한다
5. 다음 날 아침 파일이 생겼는지 확인한다

## 🔥 도전 미션 (기본을 끝냈다면)
- 브리핑을 내 이메일이나 카카오톡(나에게 보내기)으로 받기
- 13번 날씨 정보도 브리핑에 넣기
- 끝나면 자동 설정을 해제하는 법도 연습하기

```
이 스크립트를 내 맥에서 매일 아침 8시 50분에 자동 실행되게 설정하는 방법을 알려 줘. 설정 해제하는 방법도.
```
