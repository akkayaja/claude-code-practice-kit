# 15. 프롬프트를 템플릿화하기

> **얻는 능력:** AI에서 매번 같은 품질의 결과를 뽑아내는 능력

**왜 배우나요?** AI를 '그때그때 대화'로 쓰면 결과가 들쭉날쭉해요. 역할·규칙·출력형식을 정한 템플릿을 만들면 누가 써도 같은 품질이 나옵니다. 회사에서 'AI 잘 쓰는 사람'과 아닌 사람의 차이가 여기서 나요.

## 📁 들어 있는 파일
- `data/고객리뷰.csv` – 쇼핑몰 고객 리뷰 15개 (칭찬·불만·애매한 것 섞임)

## 🧭 기본 미션 (순서대로)
1. 리뷰 3개에 대해 아무 지시 없이 '답글 써 줘'라고 해 보고 결과를 기록한다
2. 템플릿을 만든다: 역할 / 말투 규칙 / 금지사항 / 출력형식(감정분류·답글·내부조치)
3. 같은 리뷰 3개로 다시 해서 결과를 비교한다
4. 15개 전체를 템플릿으로 처리해 `결과/리뷰_답글.csv`로 저장한다
5. 마음에 안 드는 결과를 보고 템플릿을 2번 이상 고친다

## 🔥 도전 미션 (기본을 끝냈다면)
- 불만 리뷰만 골라 '긴급 대응 필요'로 표시하기
- Claude API로 15개를 자동 처리하는 스크립트 만들기
- 다른 업무(회의록 요약, 이메일 답장)용 템플릿도 만들기

## 💬 Claude Code에 이렇게 말해 보세요
막히면 아래 문장을 그대로 복사해서 써도 돼요. 단, **먼저 결과를 직접 실행해 보고, 코드에서 모르는 줄은 "이 줄이 뭐 하는 거야?"라고 꼭 물어보세요.** 그래야 실력이 남아요.

```
고객리뷰.csv 의 리뷰에 답글을 다는 프롬프트 템플릿을 같이 만들고 싶어. 좋은 프롬프트 템플릿의 구성요소부터 알려 줘.
```
```
이 템플릿으로 15개 리뷰를 처리해서 감정(긍정/부정/중립), 답글, 내부 조치사항 열로 CSV를 만들어 줘.
```
```
결과 중 품질이 낮은 것 3개를 골라서 템플릿의 어느 부분을 고치면 좋을지 알려 줘.
```
