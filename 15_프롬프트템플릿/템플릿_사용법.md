# 온기마켓 AI 업무 템플릿 사용법

AI에게 일을 시킬 때 쓰는 **업무 매뉴얼(템플릿)** 모음이에요.
템플릿을 쓰면 누가 몇 번을 돌려도 같은 형식, 같은 기준으로 결과가 나와요.

## 1. 어떤 템플릿이 있나요?

| 파일 | 하는 일 | 지금 쓰는 버전 |
|---|---|---|
| `템플릿_v4.txt` | 고객 리뷰 → 감정 분류 / 답글 / 내부조치(담당팀) / 긴급도 | ✅ 최신 (v1~v3는 개선 기록용) |
| `템플릿_회의록요약.txt` | 회의 메모 → 한줄요약 / 결정사항 / 할 일 / 다음 회의 안건 | ✅ |
| `템플릿_이메일답장.txt` | 거래처 메일 → 답장 초안 + 보내기 전 확인할 것 | ✅ |

## 2. 판단 기준 (리뷰 템플릿 v4)

**감정** — 별점은 보지 않고 리뷰 *내용*만 봐요.
- 긍정: 만족·칭찬만 있음
- 부정: 불만·불편·고장·누락·교환/환불 요청이 있음 (별점이 높아도 부정)
- 중립: 칭찬과 아쉬움이 섞임, 또는 좋지도 나쁘지도 않음

**긴급도**
- 긴급 대응 필요: 고객이 *지금* 손해를 보고 있어서 오늘 직접 연락해야 함
  (고장·불량, 덜 오거나 잘못 옴, 환불·교환 요청, 답을 못 받아 화남, 교환 과정이 어려움)
- 일반: 그 밖의 경우 (긍정·중립은 항상 일반, 사진·설명서 같은 개선 의견도 일반)

## 3. 실행 방법

터미널에서 `15_프롬프트템플릿` 폴더로 들어간 뒤 실행해요.
(Claude API 키는 `03_메일분류/.env`에 있는 것을 빌려 써요. 파이썬도 03번 가상환경을 써요.)

| 하고 싶은 일 | 명령 | 결과 |
|---|---|---|
| 리뷰 전체 처리 | `../03_메일분류/.venv/bin/python 3_전체처리.py 템플릿_v4.txt` | `결과/리뷰_답글_v4.csv` |
| 회의록·이메일 처리 | `../03_메일분류/.venv/bin/python 4_다른업무.py` | `결과/회의록_요약.txt`, `결과/이메일_답장.txt` |

새 리뷰를 처리하려면 `data/고객리뷰.csv`를 같은 칸(리뷰번호, 별점, 리뷰내용)으로 바꾸면 돼요.

## 4. 새 템플릿을 만들 때 (4칸 틀)

```
[역할]      AI가 누구인지, 무슨 일을 하는지
[규칙]      말투, 길이, 판단 기준 (기준은 꼭 글로 적기!)
[금지사항]  지어내기, 여러 버전, 꾸밈, 함부로 약속하기 등
[출력형식]  "이름: 내용" 줄로 고정 → 프로그램이 칸을 나눠 표로 만들 수 있음
```

## 5. 템플릿을 고칠 때 지킬 것

1. 결과가 마음에 안 들면 **어느 줄이 왜 이상한지** 먼저 적는다.
2. 고친 템플릿은 **새 버전 파일**(v5, v6 …)로 저장하고, 고친 줄 끝에 `← v5에서 추가`처럼 표시한다.
3. 규칙을 더할 때 **반대쪽에 부딪히는 문장이 없는지** 같이 확인한다. (v4에서 "교환 절차는 일반"을 뺀 것처럼)
4. **2번 이상 돌려서** 결과가 흔들리지 않는지 확인한다.

## 6. 개선 기록

| 버전 | 고친 것 | 이유 |
|---|---|---|
| v1 | 역할·말투·금지·출력형식 | 템플릿 없이 돌리면 답글이 1~5개, 457~912자로 들쭉날쭉함 |
| v2 | 감정 기준(내용 기준) + 답글에 별점 이야기 금지 | 9번 리뷰의 감정이 실행마다 바뀜, 2·9·11번 답글에 "좋은 별점 감사" |
| v3 | 내부조치에 담당팀 + 긴급도 | 무엇부터 처리할지 안 보임 |
| v4 | 교환 과정이 어렵다는 리뷰(11번)도 긴급 | 아직 교환 중일 수 있으니 직접 도와야 함 (사장님 판단) |
