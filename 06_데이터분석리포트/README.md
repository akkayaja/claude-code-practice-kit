# 06. 공공데이터로 분석 리포트 만들기

> **얻는 능력:** 데이터를 정리하고, 질문을 세우고, 그래프로 답하는 능력

**왜 배우나요?** 데이터 분석의 핵심은 코딩이 아니라 '좋은 질문'이에요. 질문 → 분석 → 그래프 → 결론 흐름을 몸에 익힙니다.

## 📁 들어 있는 파일
- `data/지역별_카페_현황.csv` – 17개 시도의 2020~2025 분기별 카페 점포수·개업·폐업 (가상 데이터)

## 🧭 기본 미션 (순서대로)
1. 데이터를 열어 행 수, 열, 기간을 파악한다
2. 질문 3개를 직접 정한다 (예: 카페가 가장 많이 늘어난 지역은? 폐업률이 가장 높은 지역은?)
3. 질문마다 표와 그래프를 만든다
4. 그래프 아래에 '그래서 무엇을 알 수 있나' 한두 문장을 쓴다
5. 결과를 `결과/카페_분석_리포트.html`(또는 .md)로 정리한다

## 🔥 도전 미션 (기본을 끝냈다면)
- 실제 공공데이터포털(data.go.kr)에서 관심 있는 데이터를 내려받아 같은 방식으로 분석하기
- 폐업률 = 폐업 ÷ 점포수 지표를 만들어 지역 순위 매기기

## 💬 Claude Code에 이렇게 말해 보세요
막히면 아래 문장을 그대로 복사해서 써도 돼요. 단, **먼저 결과를 직접 실행해 보고, 코드에서 모르는 줄은 "이 줄이 뭐 하는 거야?"라고 꼭 물어보세요.** 그래야 실력이 남아요.

```
data/지역별_카페_현황.csv 를 요약해 줘. 기간, 지역 수, 각 열의 의미와 이상치가 있는지 알려 줘.
```
```
내 질문은 이거야: (1) ... (2) ... (3) ... 각 질문에 답하는 표와 그래프를 만들고 HTML 리포트로 묶어 줘.
```
```
이 그래프에서 잘못 해석할 수 있는 부분이 있으면 알려 줘.
```
