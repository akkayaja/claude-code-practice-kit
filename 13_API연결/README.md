# 13. API 연결하기

> **얻는 능력:** 다른 서비스의 데이터를 가져와 내 프로그램에 연결하는 능력

**왜 배우나요?** 날씨, 지도, 결제, 공공데이터, AI까지 거의 모든 자동화는 API로 연결돼요. 키 넣고 요청 보내고 응답 받는 흐름을 연습합니다.

## 📁 들어 있는 파일
- `mock_api/server.py` – 내 컴퓨터에서 도는 연습용 가짜 날씨 API 서버
- `mock_api/weather.json` – 가짜 날씨 데이터

## 🧭 기본 미션 (순서대로)
1. 터미널에서 `python3 mock_api/server.py`로 가짜 API 서버를 켠다
2. 브라우저에서 http://localhost:8765/cities 를 열어 본다
3. 키 없이 /weather?city=서울 을 요청해서 오류(401)를 확인한다
4. `?key=practice-key-123&city=서울` 로 요청해 정상 응답을 받는다
5. 파이썬으로 모든 도시 날씨를 받아 표로 출력한다
6. 없는 도시, 서버 꺼짐 같은 오류 상황을 처리한다

## 🔥 도전 미션 (기본을 끝냈다면)
- 공공데이터포털(data.go.kr)에서 실제 API 키를 발급받아 연결하기
- API 키를 코드가 아닌 .env 파일에 보관하기
- 결과를 매일 저장해 기록 쌓기 (14번과 연결)

## 💬 Claude Code에 이렇게 말해 보세요
막히면 아래 문장을 그대로 복사해서 써도 돼요. 단, **먼저 결과를 직접 실행해 보고, 코드에서 모르는 줄은 "이 줄이 뭐 하는 거야?"라고 꼭 물어보세요.** 그래야 실력이 남아요.

```
mock_api/server.py 를 켰어. API가 뭔지, 요청·응답·상태코드(200, 401, 404)가 뭔지 이 서버로 설명해 줘.
```
```
모든 도시의 날씨를 받아 표로 보여 주는 파이썬 코드를 만들어 줘. 오류가 나도 멈추지 않게 처리해 줘.
```
```
API 키를 코드에 직접 쓰면 왜 위험한지, .env 로 빼는 방법도 알려 줘.
```
