# 클로드 코드 실습 키트 (20개)

"회사를 나가도 바로 써먹을 수 있는 능력"을 만드는 연습 세트입니다.
모든 데이터는 **가짜**라서 마음껏 망가뜨려도 됩니다.

## 진행 방법
1. 폴더 번호 순서대로 진행합니다. 각 폴더의 `README.md`가 실습 안내서예요.
2. Claude Code를 **그 실습 폴더에서** 열고 시작하세요.
3. 원칙 3가지
   - **먼저 직접 보고, 직접 추측하고, 그다음 Claude에게 물어보기**
   - 결과는 반드시 **내 눈으로 검증하기** (정답 파일이 있는 실습은 비교하기)
   - 모르는 코드 줄은 "이 줄이 뭐 하는 거야?"라고 묻기
4. 끝나면 README 맨 아래 '포트폴리오 한 줄'을 채우세요. 20번에서 전부 모아 씁니다.
